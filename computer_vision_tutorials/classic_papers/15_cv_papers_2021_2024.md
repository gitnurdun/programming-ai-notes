# Classic Computer Vision Papers Collection (2000-2025): Part 5

## 41. "SAM 2: Segment Anything in Images and Videos" by Meta AI (2024)

### Introduction
SAM 2 extended the original Segment Anything Model to handle both images and videos with a unified approach, enabling real-time segmentation across modalities.

### Key Contributions
1. **Unified image-video segmentation**: Single model for both domains
2. **Memory-efficient tracking**: Efficient temporal consistency
3. **Real-time performance**: Fast inference for video applications
4. **Prompt engineering**: Advanced prompting for temporal consistency

### Architecture
- Unified backbone for spatial-temporal processing
- Memory bank for temporal consistency
- Propagation mechanism for video
- Efficient attention for temporal modeling

### Impact
SAM 2 set new standards for video segmentation and extended foundation models to temporal domains.

## 42. "MViT: Masked Vision Transformers with Improved Attention" by Fan et al. (2022)

### Introduction
MViT introduced several improvements to vision transformers including pyramid attention, global token modeling, and attention pooling.

### Key Contributions
1. **Pyramid attention**: Multi-scale attention mechanisms
2. **Global token modeling**: Efficient global context modeling
3. **Attention pooling**: Learnable pooling operations
4. **Improved efficiency**: Better performance with fewer parameters

### Architecture
- Hierarchical pyramid structure
- Global tokens for context
- Attention pooling layers
- Progressive downsampling

### Impact
MViT demonstrated how vision transformers can be made more efficient and effective.

## 43. "CMT: Convolutional Neural Networks Meet Vision Transformers" by Xu et al. (2022)

### Introduction
CMT combined the strengths of convolutional networks (local feature extraction) with transformers (global context) to achieve better performance.

### Key Contributions
1. **Hybrid architecture**: Convolution and transformer in one model
2. **Local-global features**: Combine local and global information
3. **Efficient design**: Better parameter utilization
4. **Strong performance**: Competitive with pure transformer models

### Architecture
- Convolutional layers for local features
- Transformer layers for global context
- Careful balance of convolution and attention
- Efficient feature fusion

### Impact
CMT showed that hybrid models can outperform pure CNNs or transformers.

## 44. "CoAtNet: Marrying Convolution and Attention for All Data Sizes" by Dai et al. (2022)

### Introduction
CoAtNet systematically combined convolution and attention in a principled way to achieve strong performance across different data sizes.

### Key Contributions
1. **Convolution-attention fusion**: Combine both mechanisms effectively
2. **Scaling laws**: How to scale both components together
3. **Data size adaptation**: Good performance at all scales
4. **Unified architecture**: Single approach for all use cases

### Architecture
- Convolution in early layers
- Attention in late layers
- Depth scaling strategy
- Efficient implementation

### Impact
CoAtNet demonstrated the effectiveness of combining convolution and attention.

## 45. "Vision Transformer with Convolutional Attention (CvT)" by Wu et al. (2022)

### Introduction
CvT introduced convolutional attention to vision transformers to replace the standard dot-product attention while maintaining the transformer structure.

### Key Contributions
1. **Convolutional attention**: Replace dot-product with convolution
2. **Hierarchical structure**: Multi-scale feature extraction
3. **Efficient computation**: Faster attention computation
4. **Better performance**: Improved accuracy over vanilla ViT

### Architecture
- Convolutional attention layers
- Hierarchical feature extraction
- Progressive downsampling
- Transformer-style connections

### Impact
CvT showed how convolution can improve transformer architectures.

## 46. "MaxViT: Multi-Axis Vision Transformer" by Tu et al. (2022)

### Introduction
MaxViT introduced a unified attention mechanism that combines partitioned attention with cross-shaped windows for better efficiency.

### Key Contributions
1. **Multi-axis attention**: Combine grid and window attention
2. **Partitioned attention**: Efficient attention computation
3. **Unified framework**: Single attention mechanism for all layers
4. **Better efficiency**: Improved FLOPs-accuracy trade-off

### Architecture
- Grid partitioned attention
- Cross-shaped window attention
- Unified attention mechanism
- Hierarchical structure

### Impact
MaxViT achieved strong performance with efficient attention computation.

## 47. "PVT: Pyramid Vision Transformer" by Wang et al. (2021)

### Introduction
PVT introduced a pyramid structure to vision transformers to generate multi-scale features for dense prediction tasks.

### Key Contributions
1. **Pyramid vision transformer**: Multi-scale feature generation
2. **Progressive shrinking**: Reduce spatial size gradually
3. **Spatial reduction attention**: Efficient attention mechanism
4. **Dense prediction**: Better for segmentation and detection

### Architecture
- Progressive shrinking in attention
- Multi-stage pyramid structure
- Spatial reduction in attention
- Hierarchical feature maps

### Impact
PVT demonstrated how vision transformers can be adapted for dense prediction tasks.

## 48. "SegFormer: Simple and Efficient Design for Semantic Segmentation with Transformers" by Xie et al. (2021)

### Introduction
SegFormer introduced a simple and efficient transformer architecture for semantic segmentation without complex decoding mechanisms.

### Key Contributions
1. **Simple decoder**: Lightweight MLP decoder
2. **Hierarchical transformer**: Multi-scale feature extraction
3. **No positional encoding**: Eliminate positional encoding
4. **Efficient design**: Better speed-accuracy trade-off

### Architecture
- Hierarchical Transformer encoder
- Lightweight MLP decoder
- No positional encoding needed
- Multi-stage feature fusion

### Impact
SegFormer became a standard design for transformer-based segmentation.

## 49. "Swin-Unet: Unet-like Pure Transformer for Medical Image Segmentation" by Cao et al. (2022)

### Introduction
Swin-Unet adapted the Swin Transformer architecture for medical image segmentation, combining the Swin Transformer with the U-Net structure.

### Key Contributions
1. **Transformer-based U-Net**: Pure transformer U-Net structure
2. **Medical segmentation**: Optimized for medical images
3. **Hierarchical features**: Multi-scale feature extraction
4. **Skip connections**: Cross-stage information flow

### Architecture
- Swin Transformer encoder
- Symmetric decoder structure
- Skip connections between encoder and decoder
- Hierarchical feature processing

### Impact
Swin-Unet advanced transformer-based medical image segmentation.

## 50. "TransUNet: Transformers Make Strong Encoders for Medical Image Segmentation" by Chen et al. (2021)

### Introduction
TransUNet combined Vision Transformers with U-Net to leverage the global context modeling of transformers for medical image segmentation.

### Key Contributions
1. **Transformer encoder**: Use Vision Transformer as encoder
2. **U-Net decoder**: Traditional U-Net decoder structure
3. **Global context**: Better context modeling than CNNs
4. **Medical applications**: Strong performance on medical tasks

### Architecture
- Transformer encoder with position embeddings
- U-Net style decoder
- Skip connections between encoder and decoder
- Multi-head self-attention

### Impact
TransUNet demonstrated the effectiveness of transformers for medical segmentation.
