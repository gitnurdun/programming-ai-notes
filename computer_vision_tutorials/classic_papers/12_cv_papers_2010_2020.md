# Classic Computer Vision Papers Collection (2000-2025): Part 2

## 11. "Faster R-CNN: Towards Real-Time Object Detection with Region Proposal Networks" by Ren et al. (2015)

### Introduction
Faster R-CNN introduced the Region Proposal Network (RPN) to generate region proposals, eliminating the need for external proposal methods and enabling end-to-end training.

### Key Contributions
1. **Region Proposal Network**: Learnable proposal generation
2. **Shared features**: RPN and detection network share convolutional features
3. **Anchor boxes**: Multi-scale, multi-ratio proposal boxes
4. **End-to-end training**: Joint training of proposal and detection

### Architecture
- Shared convolutional features
- RPN for proposal generation
- ROI pooling
- Classification and regression heads

### Impact
Faster R-CNN set the standard for two-stage object detection and influenced many subsequent methods.

---

## 12. "Mask R-CNN" by He et al. (2017)

### Introduction
Mask R-CNN extended Faster R-CNN to perform instance segmentation by adding a branch for predicting segmentation masks on each Region of Interest.

### Key Contributions
1. **Instance segmentation**: Pixel-level mask prediction
2. **ROIAlign**: Improved spatial alignment for precise localization
3. **Parallel branches**: Classification, bounding box, and mask prediction
4. **Simple extension**: Minimal overhead over Faster R-CNN

### Architecture
- Backbone network (ResNet-FPN)
- Region Proposal Network
- ROIAlign for feature extraction
- Parallel prediction heads

### Impact
Mask R-CNN became the foundation for instance segmentation and influenced many subsequent approaches.

---

## 13. "SSD: Single Shot MultiBox Detector" by Liu et al. (2016)

### Introduction
SSD introduced a single-shot detection method that predicts object classes and bounding boxes directly from feature maps at multiple scales.

### Key Contributions
1. **Single-shot detection**: No region proposals needed
2. **Multi-scale feature maps**: Predictions at different resolutions
3. **Default boxes**: Predefined boxes at different scales and aspect ratios
4. **End-to-end training**: Direct optimization

### Architecture
- Base network for feature extraction
- Auxiliary convolutional layers for multi-scale detection
- Default boxes at each location
- Non-maximum suppression

### Impact
SSD demonstrated that high accuracy could be achieved with single-shot methods, competing with two-stage approaches.

---

## 14. "MobileNets: Efficient Convolutional Neural Networks for Mobile Vision Applications" by Howard et al. (2017)

### Introduction
MobileNet introduced depthwise separable convolutions to significantly reduce computational cost while maintaining reasonable accuracy, making CNNs practical for mobile devices.

### Key Contributions
1. **Depthwise separable convolutions**: Factorized standard convolutions
2. **Model size reduction**: Significantly fewer parameters
3. **Efficient inference**: Optimized for mobile deployment
4. **Width multiplier**: Trade accuracy for efficiency

### Architecture
- Depthwise convolution: spatial filtering per channel
- Pointwise convolution: 1×1 convolution for channel combination
- Width multiplier: reduce number of channels
- Resolution multiplier: reduce input resolution

### Impact
MobileNet became the standard for efficient mobile vision applications and inspired many subsequent efficient architectures.

---

## 15. "EfficientNet: Rethinking Model Scaling for Convolutional Neural Networks" by Tan & Le (2019)

### Introduction
EfficientNet proposed a principled method for scaling up networks by balancing network depth, width, and resolution, achieving better accuracy and efficiency.

### Key Contributions
1. **Compound scaling**: Uniform scaling of depth, width, and resolution
2. **Neural architecture search**: Found optimal baseline network
3. **Pareto efficiency**: Better accuracy-efficiency trade-offs
4. **Scalable design**: EfficientNet-B0 to EfficientNet-B7

### Methodology
- Baseline network using NAS
- Compound scaling using fixed ratios
- Grid search for optimal scaling coefficients
- Model variants with different resource constraints

### Impact
EfficientNet achieved state-of-the-art performance with significantly fewer parameters and FLOPS.

## 16. "Vision Transformers for Dense Prediction" by Wang et al. (2021)

### Introduction
This work adapted Vision Transformers for dense prediction tasks like semantic segmentation, showing that transformers can effectively handle pixel-level tasks.

### Key Contributions
1. **Transformer adaptation**: Modified ViT for dense prediction
2. **Multi-scale features**: Pyramid structure for different resolutions
3. **Attention mechanisms**: Self-attention for global context
4. **Segmentation head**: Specialized decoder for segmentation

### Architecture
- Patch embedding
- Transformer encoder
- Multi-scale feature pyramid
- Segmentation decoder

### Impact
Demonstrated the effectiveness of transformers for dense prediction tasks.

---

## 17. "An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale" by Dosovskiy et al. (2020)

### Introduction
Vision Transformer (ViT) showed that transformers can be directly applied to image classification by treating image patches as tokens, achieving excellent results when trained on large datasets.

### Key Contributions
1. **Patch-based processing**: Divide images into patches
2. **Transformer architecture**: Apply standard transformer to image patches
3. **Position embeddings**: Encode spatial information
4. **Large-scale training**: Effective with sufficient data

### Architecture
- Patch embedding
- Position embeddings
- Transformer encoder
- Classification head

### Impact
ViT demonstrated that transformers can outperform CNNs on image classification, inspiring numerous vision transformer variants.

---

## 18. "Swin Transformer: Hierarchical Vision Transformer using Shifted Windows" by Liu et al. (2021)

### Introduction
Swin Transformer introduced shifted windows to enable hierarchical feature representation in vision transformers while maintaining computational efficiency.

### Key Contributions
1. **Shifted windows**: Efficient attention computation
2. **Hierarchical structure**: Multi-scale feature maps
3. **Local attention**: Limited to local windows
4. **Cross-window connections**: Enable global modeling

### Architecture
- Patch partition
- Linear embedding
- Hierarchical Swin Transformer blocks
- Shifted window attention

### Impact
Swin Transformer became the foundation for many vision transformer applications, especially dense prediction tasks.

---

## 19. "NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis" by Mildenhall et al. (2020)

### Introduction
NeRF introduced neural radiance fields for novel view synthesis, representing 3D scenes as continuous volumetric scenes that can be rendered from novel viewpoints.

### Key Contributions
1. **Neural radiance fields**: Continuous scene representation
2. **Volume rendering**: Render novel views through volume rendering
3. **Positional encoding**: Enable high-frequency details
4. **View-dependent effects**: Model appearance changes with viewpoint

### Methodology
- MLP to represent scene
- Volume rendering for novel view synthesis
- Positional encoding for detail preservation
- Hierarchical sampling for efficiency

### Impact
NeRF revolutionized novel view synthesis and 3D scene representation, spawning numerous extensions and applications.

## 20. "StyleGAN: A Style-Based Generator Architecture for Generative Adversarial Networks" by Karras et al. (2019)

### Introduction
StyleGAN introduced a new generator architecture that enables fine-grained control over image generation through style-based modulation.

### Key Contributions
1. **Style-based generator**: Modulate activation maps with style
2. **Adaptive instance normalization**: AdaIN for style transfer
3. **Progressive growing**: Train progressively from low to high resolution
4. **Latent space disentanglement**: Better control over generated images

### Architecture
- Mapping network: latent code to style vector
- Synthesis network: generate images from style vectors
- AdaIN: Adaptive instance normalization
- Progressive growing

### Impact
StyleGAN achieved state-of-the-art image generation quality and enabled fine-grained control over image attributes.
