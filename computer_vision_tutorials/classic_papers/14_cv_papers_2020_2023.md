# Classic Computer Vision Papers Collection (2000-2025): Part 4

## 31. "Swin Transformer V2: Scaling Up Capacity and Resolution" by Liu et al. (2022)

### Introduction
Swin Transformer V2 addressed the challenges of scaling up Swin Transformers to higher resolutions and larger model sizes while maintaining training stability.

### Key Contributions
1. **Post-norm design**: Improved training stability for large models
2. **Scaled ReLU**: Better activation for large models
3. **Log-spaced continuous position bias**: Handle higher resolution images
4. **Transfer learning**: Effective scaling from pre-trained models

### Architecture
- Modified Swin Transformer blocks
- Post-norm instead of pre-norm
- Scaled ReLU activation
- Enhanced position bias mechanism

### Impact
Swin Transformer V2 enabled scaling up to much larger models with better performance.

## 32. "MAE: Masked Autoencoders Are Scalable Vision Learners" by He et al. (2022)

### Introduction
Masked Autoencoders (MAE) introduced an efficient self-supervised learning method for vision transformers by masking random patches during pre-training.

### Key Contributions
1. **Asymmetric encoder-decoder**: Masked patches only in encoder
2. **High masking ratio**: 75% masking for efficiency
3. **Simple reconstruction**: Reconstruct normalized pixel values
4. **Scalable learning**: Effective with large models and datasets

### Architecture
- Vision Transformer encoder (only on visible patches)
- Lightweight decoder (applied to all patches)
- Masked image modeling task
- Pixel-level reconstruction

### Impact
MAE demonstrated that masked autoencoding is highly effective for vision pre-training.

## 33. "BEiT: BERT Pre-Training of Image Transformers" by Bao et al. (2022)

### Introduction
BEiT adapted the BERT approach to vision by pre-training image transformers with masked image modeling using visual tokens.

### Key Contributions
1. **Visual tokenization**: VQ-VAE for discrete image representation
2. **Masked image modeling**: Masked reconstruction task
3. **BERT-inspired pre-training**: Language model techniques for vision
4. **Effective transfer**: Good performance on downstream tasks

### Architecture
- VQ-VAE tokenizer
- Vision Transformer encoder
- Masked modeling objective
- Discrete token prediction

### Impact
BEiT showed that BERT-style pre-training is effective for vision transformers.

## 34. "DINO: Emerging Properties in Self-Supervised Vision Transformers" by Caron et al. (2021)

### Introduction
DINO introduced a self-supervised learning method for vision transformers without requiring negative samples, achieving remarkable self-supervised performance.

### Key Contributions
1. **Self-distillation**: Teacher-student framework without negative samples
2. **Centering**: Prevent model collapse without negative pairs
3. **Multi-crop**: Use multiple crops for training
4. **Emergent properties**: Self-supervised features show semantic understanding

### Architecture
- Student and teacher networks
- Multi-crop data augmentation
- Centering mechanism
- Self-distillation loss

### Impact
DINO demonstrated that self-supervised learning can achieve impressive results without labeled data.

---

## 35. "CLIP: Learning Transferable Visual Models From Natural Language Supervision" by Radford et al. (2021)

### Introduction
CLIP learned transferable visual representations by training on 400 million image-text pairs, enabling zero-shot transfer to various vision tasks.

### Key Contributions
1. **Contrastive learning**: Align images and text in shared space
2. **Zero-shot transfer**: Generalize to unseen tasks without fine-tuning
3. **Large-scale training**: Leverage web-crawled data
4. **Dual encoder**: Independent processing of modalities

### Architecture
- Image encoder (Vision Transformer or ResNet)
- Text encoder (Transformer)
- Contrastive loss
- Cross-modal similarity computation

### Impact
CLIP showed the power of large-scale contrastive learning for generalizable vision representations.

## 36. "ALIGN: Scaling Up Visual and Vision-Language Understanding With Noisy Text Supervision" by Jia et al. (2021)

### Introduction
ALIGN demonstrated that large-scale noisy image-text data can be used to train high-quality vision-language models, scaling up to 1.8 billion image-text pairs.

### Key Contributions
1. **Noisy data training**: Handle large-scale noisy data
2. **Scaling laws**: Performance improves with data scale
3. **Efficient filtering**: Filter data based on image-text similarity
4. **Large-scale training**: Billion-scale dataset training

### Architecture
- Efficient ResNet backbone
- Transformer text encoder
- Contrastive learning objective
- Data filtering mechanisms

### Impact
ALIGN showed that noisy large-scale data can be effectively leveraged for vision-language learning.

## 37. "Florence: A New Foundation Model for Computer Vision" by Yuan et al. (2021)

### Introduction
Florence introduced a unified framework for various computer vision tasks by learning task-specific representations through prompting.

### Key Contributions
1. **Task prompting**: Unify different vision tasks with text prompts
2. **Unified architecture**: Single model for multiple tasks
3. **Foundation model**: Generalizable visual understanding
4. **Prompt learning**: Task-specific prompting for different tasks

### Architecture
- Vision Transformer backbone
- Text prompt integration
- Task-specific heads
- Cross-modal attention

### Impact
Florence demonstrated how prompting can unify multiple vision tasks in a single model.

## 38. "GLIP: Grounded Language-Image Pre-training" by Li et al. (2022)

### Introduction
GLIP unified object detection and phrase grounding by learning from both image-text pairs and referring expression data.

### Key Contributions
1. **Unified grounding**: Combine detection and referring expression
2. **Phrase grounding**: Ground text phrases in images
3. **Self-training**: Improve with referring expression data
4. **Zero-shot detection**: Detect objects without category names

### Architecture
- Vision-language transformer
- Grounding pre-training objective
- Phrase-object alignment
- Self-training mechanism

### Impact
GLIP showed how grounding can improve both detection and language understanding.

## 39. "Grounding DINO: Marrying DINO with Grounded Pre-Training for Open-Set Object Detection" by Liu et al. (2023)

### Introduction
Grounding DINO combined the DINO detection framework with grounding capabilities for open-set object detection using text prompts.

### Key Contributions
1. **Text-conditioned detection**: Detect objects based on text descriptions
2. **Open-vocabulary detection**: Detect unseen object categories
3. **Unified framework**: Combine detection with grounding
4. **Strong performance**: State-of-the-art open-vocabulary detection

### Architecture
- Text-guided query selection
- Language-guided feature alignment
- DINO-based detection framework
- Cross-modal fusion

### Impact
Grounding DINO advanced open-vocabulary object detection significantly.

## 40. "YOLOv9: Learning What You Want to Learn Using Programmable Gradient Information" by Wang et al. (2024)

### Introduction
YOLOv9 introduced Programmable Gradient Information (PGI) to help deep networks learn better by providing auxiliary tasks for better gradient flow.

### Key Contributions
1. **Programmable Gradient Information**: Auxiliary tasks for better gradient flow
2. **Generative Adversarial Network**: For feature learning
3. **Multi-level feature learning**: Multiple levels of feature representation
4. **Improved efficiency**: Better performance with similar computational cost

### Architecture
- PGI mechanism
- Generative intermediate features
- Multi-level learning
- Efficient backbone design

### Impact
YOLOv9 pushed the frontier of real-time object detection with improved accuracy.
