# 预处理器与宏 (C++11-20)

## 一、静态断言（static_assert）

### 1.1 基本用法

```cpp
// 编译时断言
static_assert(sizeof(int) == 4, "int must be 4 bytes");

static_assert(true, "This will always pass");

// C++17: 可以省略消息
static_assert(sizeof(int) == 4);
```

### 1.2 应用场景

```cpp
// 检查类型特性
template<typename T>
class Container {
    static_assert(std::is_default_constructible_v<T>,
                  "T must be default constructible");
};

// 检查平台
static_assert(sizeof(void*) == 8, "Requires 64-bit platform");

// 检查数组大小
template<typename T, size_t N>
class Array {
    static_assert(N > 0, "Array size must be greater than 0");
};
```

## 二、_Pragma

### 2.1 基本用法

```cpp
// _Pragma操作符
_Pragma("warning(push)")
_Pragma("warning(disable: 4996)")
void old_function() {}
_Pragma("warning(pop)")

// 等价于
#pragma warning(push)
#pragma warning(disable: 4996)
void old_function2() {}
#pragma warning(pop)
```

## 三、__has_include (C++17)

``` 2.1 基本用法

```cpp
// 检查头文件是否存在
#if __has_include(<optional>)
    #include <optional>
    using std::optional;
#else
    #include <experimental/optional>
    using std::experimental::optional;
#endif

// 检查自定义头文件
#if __has_include("myheader.h")
    #include "myheader.h"
#endif
```

## 四、__LINE__, __FILE__, __func__

### 4.1 预定义宏

```cpp
// 预定义宏
void debug_info() {
    std::cout << "File: " << __FILE__ << std::endl;
    std::cout << "Line: " << __LINE__ << std::endl;
    std::cout << "Function: " << __func__ << std::endl;
    std::cout << "Date: " << __DATE__ << std::endl;
    std::cout << "Time: " << __TIME__ << std::endl;
}
```

## 五、面试常见问题

### Q1: static_assert有什么用途？

**答案：**
static_assert用于编译时断言，检查编译时条件。

### Q2: _Pragma有什么用途？

**答案：**
_Pragma用于在代码中嵌入编译器指令。

### Q3: __has_include有什么用途？

**答案：**
__has_include用于检查头文件是否存在，实现跨平台兼容。

## 六、最佳实践

### 6.1 使用static_assert检查约束

```cpp
template<typename T>
void process(T value) {
    static_assert(std::is_integral_v<T>, "T must be integral");
}
```

### 6.2 使用__has_include实现兼容性

```cpp
#if __has_include(<filesystem>)
    #include <filesystem>
    namespace fs = std::filesystem;
#else
    #include <experimental/filesystem>
    namespace fs = std::experimental::filesystem;
#endif
```

## 七、总结

预处理器和宏是C++的重要特性：

**核心概念：**
1. static_assert编译时断言
2. _Pragma操作符
3. __has_include检查头文件
4. 预定义宏

**最佳实践：**
1. 优先使用constexpr和static_assert
2. 使用__has_include实现兼容性
3. 避免复杂的宏定义

掌握这些特性可以写出更安全、更可移植的C++代码。
