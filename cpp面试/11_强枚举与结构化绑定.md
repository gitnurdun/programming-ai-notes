# 强枚举与结构化绑定 (C++11-17)

## 一、强类型枚举（enum class）

### 1.1 基本用法

```cpp
// C++11: 强类型枚举
enum class Color {
    Red,
    Green,
    Blue
};

// 使用
Color c = Color::Red;
// Color c2 = Red;  // 错误：必须指定枚举类型

// 不能隐式转换为int
// int x = c;  // 错误
int x = static_cast<int>(c);  // 正确：显式转换
```

### 1.2 指定底层类型

```cpp
// 指定底层类型
enum class Color : uint8_t {
    Red = 0,
    Green = 1,
    Blue = 2
};

enum class Status : int {
    OK = 0,
    Error = -1,
    Pending = 1
};

// 使用
static_assert(sizeof(Color) == 1);
static_assert(sizeof(Status) == 4);
```

### 1.3 前向声明

```cpp
// 前向声明
enum class Color : uint8_t;

// 定义
enum class Color : uint8_t {
    Red,
    Green,
    Blue
};

// 使用
void set_color(Color c);
```

## 二、结构化绑定（C++17）

### 2.1 基本用法

```cpp
// 解构pair
std::pair<int, std::string> p = {42, "Hello"};
auto [id, name] = p;
std::cout << id << ": " << name << std::endl;

// 解构tuple
std::tuple<int, double, std::string> t = {1, 3.14, "World"};
auto [i, d, s] = t;
```

### 2.2 解构结构体

```cpp
struct Point {
    double x, y, z;
};

Point p = {1.0, 2.0, 3.0};
auto [x, y, z] = p;
```

### 2.3 解构数组

```cpp
int arr[3] = {1, 2, 3};
auto [a, b, c] = arr;
```

### 2.4 解构自定义类型

```cpp
class MyClass {
public:
    int a, b;
    
    // 为结构化绑定提供tuple_size、tuple_element和get
    template<size_t I>
    auto& get() {
        if constexpr (I == 0) return a;
        else if constexpr (I == 1) return b;
    }
};

// 特化std::tuple_size
template<>
struct std::tuple_size<MyClass> : std::integral_constant<size_t, 2> {};

// 特化std::tuple_element
template<size_t I>
struct std::tuple_element<I, MyClass> {
    using type = std::conditional_t<I == 0, int, int>;
};

// 特化std::get
template<size_t I>
auto& get(MyClass& obj) {
    return obj.template get<I>();
}

// 使用
MyClass obj{10, 20};
auto [x, y] = obj;
```

## 三、面试常见问题

### Q1: enum class和enum有什么区别？

**答案：**
- **enum class**: 强类型，作用域限定，不隐式转换
- **enum**: 弱类型，全局作用域，隐式转换为int

### Q2: 如何为enum class指定底层类型？

**答案：**
```cpp
enum class Color : uint8_t {
    Red,
    Green,
    Blue
};
```

### Q3: 结构化绑定支持哪些类型？

**答案：**
1. 数组
2. 结构体/类（所有成员都是public）
3. tuple/pair
4. 自定义类型（提供tuple_size、tuple_element、get）

### Q4: 结构化绑定如何与auto一起使用？

**答案：**
```cpp
auto [x, y, z] = point;
const auto [a, b] = pair;
auto& [ref1, ref2] = tuple;  // 引用
```

## 四、最佳实践

### 4.1 优先使用enum class

```cpp
// 好的实践
enum class Color { Red, Green, Blue };

// 避免
enum Color { Red, Green, Blue };
```

### 4.2 为enum class指定底层类型

```cpp
enum class Color : uint8_t { Red, Green, Blue };
```

### 4.3 使用结构化绑定简化代码

```cpp
// 好的实践
auto [x, y, z] = get_point();

// 避免
auto point = get_point();
auto x = point.x;
auto y = point.y;
auto z = point.z;
```

## 五、总结

强枚举和结构化绑定是现代C++的重要特性：

**强枚举：**
- 类型安全
- 作用域限定
- 可指定底层类型

**结构化绑定：**
- 简化代码
- 提高可读性
- 支持多种类型

掌握这些特性可以写出更安全、更简洁的C++代码。
