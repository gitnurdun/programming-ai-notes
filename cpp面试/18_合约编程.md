# 合约编程（Contracts）(C++26预期)

## 一、合约概述

### 1.1 什么是合约

合约编程是一种通过前置条件、后置条件和不变量来规范程序行为的方法。

**核心概念：**
1. 前置条件（Precondition）：函数调用前必须满足的条件
2. 后置条件（Postcondition）：函数调用后必须满足的条件
3. 不变量（Invariant）：类对象必须始终保持的条件

### 1.2 合约语法（预期）

```cpp
// 合约语法（C++26预期）
#include <contracts>

int divide(int a, int b)
    [[expects: b != 0]]  // 前置条件
    [[ensures: r: r == a / b]]  // 后置条件
{
    return a / b;
}

class Container {
public:
    void push_back(int value)
        [[expects: size_ < capacity_]]  // 前置条件
    {
        data_[size_++] = value;
    }
    
    [[ensures: size() >= 0]]  // 不变量
    size_t size() const { return size_; }
    
private:
    int data_[100];
    size_t size_ = 0;
};
```

## 二、前置条件

### 2.1 基本用法

```cpp
// 前置条件
int array_access(int* arr, int index)
    [[expects: arr != nullptr]]
    [[expects: index >= 0]]
{
    return arr[index];
}

// 复杂前置条件
void process_string(std::string_view str)
    [[expects: !str.empty()]]
    [[expects: str.size() <= 100]]
{
    // 处理字符串
}
```

## 三、后置条件

### 3.1 基本用法

```cpp
// 后置条件
int calculate(int x)
    [[ensures: r: r >= 0]]
{
    return x * x;
}

// 引用旧值
int increment(int& value)
    [[ensures old: value == old + 1]]
{
    return ++value;
}
```

## 四、不变量

### 4.1 类不变量

class Stack {
public:

        [[expects: size_ < capacity_]]

        data_[size_++] = value;
    }
    
    int pop()
        [[expects: size_ > 0]]
        [[ensures: size() == old_size - 1]]
    {
        return data_[--size_];
    }
    
    [[ensures: size() >= 0]]
    [[ensures: size() <= capacity_]]
    size_t size() const { return size_; }
    
private:
    int data_[100];
    size_t size_ = 0;
    static constexpr size_t capacity_ = 100;
};

## 五、面试常见问题

**答案：**
前置条件检查函数调用前必须满足的条件。

### Q3: 后置条件的用途是什么？

**答案：**
