# C++11-20新关键字详解

## 一、nullptr

### 1.1 基本用法

```cpp
// nullptr是C++11引入的空指针常量
int* ptr = nullptr;
std::shared_ptr<int> sptr = nullptr;

// 与0和NULL的区别
void func(int x);      // 重载1
void func(char* ptr);  // 重载2

func(0);       // 调用func(int)
func(NULL);    // 可能调用func(int)，取决于NULL的定义
func(nullptr); // 调用func(char*)，明确意图
```

### 1.2 nullptr的优势

```cpp
// 1. 类型安全
std::nullptr_t nptr = nullptr;
if (nptr == nullptr) { /* ... */ }

// 2. 模板友好
template<typename T>
void func(T* ptr) {
    if (ptr == nullptr) { /* ... */ }
}

func<int>(nullptr);  // 明确传递空指针

// 3. 避免重载歧义
void overload(int);
void overload(double*);

overload(nullptr);  // 明确调用overload(double*)
```

## 二、decltype

### 2.1 基本用法

```cpp
// 推导表达式类型
int x = 42;
decltype(x) y = 100;  // y的类型是int

// 推导函数返回类型
int func();
decltype(func()) z = func();  // z的类型是int

// 推导复杂表达式
std::vector<int> vec;
decltype(vec.begin()) it = vec.begin();
```

### 2.2 decltype(auto)

```cpp
// C++14: decltype(auto)
template<typename T>
auto get_value(T& container) -> decltype(auto) {
    return container[0];  // 保持引用类型
}

// 对比auto
template<typename T>
auto get_value_auto(T& container) {
    return container[0];  // 丢失引用类型
}
```

## 三、auto

### 3.1 基本用法

```cpp
// 类型推导
auto x = 42;                    // int
auto y = 3.14;                  // double
auto z = "hello";               // const char*
auto vec = std::vector<int>();  // std::vector<int>

// 迭代器
std::vector<int> v = {1, 2, 3};
auto it = v.begin();  // std::vector<int>::iterator

// 范围for
for (auto elem : v) {
    std::cout << elem << std::endl;
}
```

### 3.2 函数返回类型推导

```cpp
// C++14: 自动推导返回类型
auto add(int a, int b) {
    return a + b;  // 返回int
}

auto get_string() {
    return "Hello";  // 返回const char*
}

// 尾返回类型
template<typename T, typename U>
auto add(T a, U b) -> decltype(a + b) {
    return a + b;
}
```

### 3.3 通用lambda

```cpp
// C++14: 泛型lambda
auto lambda = [](auto x, auto y) {
    return x + y;
};

lambda(1, 2);        // int
lambda(1.5, 2.5);    // double
lambda(std::string("Hello "), "World");  // std::string
```

## 四、noexcept

### 4.1 基本用法

```cpp
// noexcept说明符
void func() noexcept {
    // 不会抛出异常
}

// 条件noexcept
void func2() noexcept(noexcept(some_function())) {
    some_function();
}

// noexcept运算符
constexpr bool will_throw = noexcept(func());  // false
```

### 4.2 noexcept的重要性

```cpp
class MyClass {
public:
    // 移动操作应该是noexcept
    MyClass(MyClass&& other) noexcept 
        : data_(other.data_) {
        other.data_ = nullptr;
    }
    
    // 如果移动操作可能抛出异常，STL会使用拷贝
};

// 原因：STL容器在重新分配时优先使用移动操作
// 如果移动操作可能抛出异常，会回退到拷贝操作
```

## 五、override和final

### 5.1 override

```cpp
class Base {
public:
    virtual void func1() {}
    virtual void func2(int x) {}
};

class Derived : public Base {
public:
    // override: 确保覆盖基类虚函数
    void func1() override {
        std::cout << "Derived func1" << std::endl;
    }
    
    // 错误：没有对应的基类虚函数
    // void func3() override {}
    
    // 错误：参数不匹配
    // void func2(double x) override {}
};
```

### 5.2 final

```cpp
class Base {
public:
    virtual void func() {}
};

class Derived : public Base {
public:
    // final: 禁止进一步覆盖
    void func() final {
        std::cout << "Derived func (final)" << std::endl;
    }
};

class FurtherDerived : public Derived {
public:
    // 错误：func是final，不能覆盖
    // void func() override {}
};

// final也可以用于类
class FinalClass final {
    // 不能被继承
};

// 错误：FinalClass是final
// class DerivedFromFinal : public FinalClass {};
```

## 六、default和delete

### 6.1 default

```cpp
class MyClass {
public:
    // 显式请求默认构造函数
    MyClass() = default;
    
    // 显式请求析构函数
    ~MyClass() = default;
    
    // 显式请求拷贝构造函数
    MyClass(const MyClass&) = default;
    
    // 显式请求拷贝赋值运算符
    MyClass& operator=(const MyClass&) = default;
    
    // 显式请求移动构造函数
    MyClass(MyClass&&) = default;
    
    // 显式请求移动赋值运算符
    MyClass& operator=(MyClass&&) = default;
};
```

### 6.2 delete

```cpp
class MyClass {
public:
    // 禁止默认构造函数
    MyClass() = delete;
    
    // 禁止拷贝
    MyClass(const MyClass&) = delete;
    MyClass& operator=(const MyClass&) = delete;
    
    // 禁止移动
    MyClass(MyClass&&) = delete;
    MyClass& operator=(MyClass&&) = delete;
    
    // 禁止特定参数类型
    void func(int) = delete;
    void func(double) = delete;
    void func(std::string) = delete;
};
```

## 七、constexpr

### 7.1 constexpr函数

```cpp
// constexpr函数可以在编译时求值
constexpr int square(int x) {
    return x * x;
}

// 编译时计算
constexpr int result = square(5);  // 25
static_assert(square(5) == 25);

// 也可以运行时计算
int value = 10;
int runtime_result = square(value);  // 100
```

### 7.2 constexpr变量

```cpp
// constexpr变量必须在编译时初始化
constexpr int max_size = 100;
constexpr double pi = 3.14159265358979323846;

// 可以用于数组大小
int arr[max_size];  // OK
```

## 八、requires (C++20)

### 8.1 requires表达式

```cpp
// requires表达式
template<typename T>
concept Addable = requires(T a, T b) {
    { a + b } -> std::convertible_to<T>;
};

// 使用requires子句
template<typename T>
requires Addable<T>
T add(T a, T b) {
    return a + b;
}

// 简化语法
template<Addable T>
T add(T a, T b) {
    return a + b;
}
```

## 九、co_await, co_yield, co_return (C++20)

### 9.1 协程关键字

```cpp
// co_await: 等待异步操作
auto result = co_await async_operation();

// co_yield: 产生一个值并挂起
co_yield value;

// co_return: 从协程返回
co_return result;
```

## 十、consteval和constinit (C++20)

### 10.1 consteval

```cpp
// consteval: 必须在编译时求值
consteval int square(int x) {
    return x * x;

constexpr int result = square(5);  // OK
// int runtime = square(10);       // 错误
```

### 10.2 constinit

```cpp
// constinit: 必须在编译时初始化
constinit int global_var = 42;

// 确保静态初始化
// constinit int x = get_value();  // 错误
```

## 十一、面试常见问题

### Q1: nullptr和0有什么区别？

**答案：**
- **nullptr**: 空指针常量，类型是std::nullptr_t
- **0**: 整数常量，可以隐式转换为指针

nullptr类型更安全，避免重载歧义。

### Q2: auto和decltype有什么区别？

**答案：**
- **auto**: 推导表达式的类型，丢弃引用和const
- **decltype**: 推导表达式的确切类型，保留引用和const

### Q3: noexcept的作用是什么？

**答案：**
noexcept指示函数不会抛出异常，帮助编译器优化，允许STL使用移动操作。

### Q4: override和final的作用是什么？

**答案：**
- **override**: 确保函数覆盖基类虚函数
- **final**: 禁止函数被进一步覆盖或类被继承

### Q5: default和delete的作用是什么？

**答案：**
- **= default**: 显式请求编译器生成默认版本
- **= delete**: 显式禁止某个函数

## 十二、总结

C++11-20引入了许多新关键字：

**核心关键字：**
1. nullptr: 空指针常量
2. decltype: 推导表达式类型
3. auto: 类型推导
4. noexcept: 异常说明
5. override/final: 虚函数控制
6. default/delete: 特殊成员函数控制
7. constexpr: 常量表达式
8. requires: 概念约束（C++20）
9. 协程关键字: co_await, co_yield, co_return（C++20）
10. consteval/constinit: 编译时初始化（C++20）

掌握这些关键字是现代C++开发的基本技能。
