# 常量表达式与断言 (C++11-20)

## 一、constexpr

### 1.1 constexpr函数

```cpp
// C++11: constexpr函数
constexpr int square(int x) {
    return x * x;
}

// 编译时计算
constexpr int result = square(5);  // 25
static_assert(square(5) == 25);

// 也可以运行时计算
int value = 10;
int runtime_result = square(value);  // 100
```

### 1.2 constexpr变量

```cpp
// constexpr变量必须在编译时初始化
constexpr int max_size = 100;
constexpr double pi = 3.14159265358979323846;

// 可以用于数组大小
int arr[max_size];  // OK

// constexpr引用
constexpr const int& ref = max_size;

// constexpr指针
constexpr const int* ptr = &max_size;
```

### 1.3 constexpr构造函数

```cpp
class Point {
public:
    constexpr Point(double x, double y) : x_(x), y_(y) {}
    
    constexpr double x() const { return x_; }
    constexpr double y() const { return y_; }
    
    constexpr double distance() const {
        return std::sqrt(x_ * x_ + y_ * y_);
    }
    
private:
    double x_, y_;
};

// 编译时构造
constexpr Point origin(0, 0);
constexpr Point p(3, 4);
constexpr double dist = p.distance();  // 5.0
```

### 1.4 C++14 relaxed constexpr

```cpp
// C++11: 只能有一个return语句
constexpr int factorial_c11(int n) {
    return n <= 1 ? 1 : n * factorial_c11(n - 1);
}

// C++14: 可以有多个语句
constexpr int factorial_c14(int n) {
    int result = 1;
    for (int i = 2; i <= n; ++i) {
        result *= i;
    }
    return result;
}

// C++14: 可以使用局部变量、if语句、循环
constexpr int gcd(int a, int b) {
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}
```

### 1.5 C++17 if constexpr

```cpp
// 编译时条件分支
template<typename T>
auto get_value(T value) {
    if constexpr (std::is_pointer_v<T>) {
        return *value;  // 如果是指针，解引用
    } else {
        return value;   // 否则直接返回
    }
}

// 使用
int x = 42;
std::cout << get_value(x) << std::endl;      // 42
std::cout << get_value(&x) << std::endl;     // 42
```

## 二、consteval和constinit (C++20)

### 2.1 consteval

```cpp
// consteval: 必须在编译时求值
consteval int square(int x) {
    return x * x;
}

// 编译时计算
constexpr int result = square(5);  // OK

// 错误：不是常量表达式
// int runtime_result = square(10);  // 编译错误
```

### 2.2 constinit

```cpp
// constinit: 必须在编译时初始化
constinit int global_var = 42;

// 确保静态初始化，避免动态初始化顺序问题
constinit std::string_view sv = "Hello";

// 错误：不是常量初始化
// constinit int x = get_value();  // 编译错误
```

## 三、static_assert

### 3.1 基本用法

```cpp
// 编译时断言
static_assert(sizeof(int) == 4, "int must be 4 bytes");

static_assert(true, "This will always pass");

// 错误示例
// static_assert(false, "This will fail");
```

### 3.2 C++17 static_assert

```cpp
// C++17: 可以省略消息
static_assert(sizeof(int) == 4);

// 更简洁
static_assert(std::is_integral_v<int>);
static_assert(std::is_same_v<int, int>);
```

### 3.3 static_assert应用

```cpp
// 检查类型特性
template<typename T>
class Container {
    static_assert(std::is_default_constructible_v<T>,
                  "T must be default constructible");
    static_assert(std::is_copy_constructible_v<T>,
                  "T must be copy constructible");
};

// 检查数组边界
template<typename T, size_t N>
class Array {
    static_assert(N > 0, "Array size must be greater than 0");
};

// 检查平台特性
static_assert(sizeof(void*) == 8, "Requires 64-bit platform");
```

## 四、面试常见问题

### Q1: constexpr和const有什么区别？

**答案：**
- **const**: 只读变量，可以在运行时初始化
- **constexpr**: 常量表达式，必须在编译时初始化

### Q2: consteval和constexpr有什么区别？

**答案：**
- **constexpr**: 可以在编译时或运行时求值
- **consteval**: 必须在编译时求值

### Q3: if constexpr有什么用途？

**答案：**
if constexpr用于编译时条件分支，根据类型特征编译不同代码，避免实例化不使用的分支。

### Q4: static_assert有什么用途？

**答案：**
static_assert用于编译时断言，检查编译时条件，如果条件为假则编译失败。

## 五、最佳实践

### 5.1 优先使用constexpr

```cpp
// 好的实践
constexpr int square(int x) {
    return x * x;
}

// 而不是
#define SQUARE(x) ((x) * (x))
```

### 5.2 使用static_assert检查类型

```cpp
template<typename T>
void process(T value) {
    static_assert(std::is_integral_v<T>, "T must be integral");
    // ...
}
```

## 六、总结

constexpr和static_assert是C++编译时编程的重要工具：

**核心概念：**
1. constexpr函数和变量
2. consteval强制编译时求值
3. constinit强制编译时初始化
4. static_assert编译时断言

**优势：**
1. 编译时计算
2. 零运行时开销
3. 类型安全
4. 更好的错误信息

掌握constexpr和static_assert是现代C++开发的基本技能。
