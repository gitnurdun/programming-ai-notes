# C++11-23 新特性总览

## 一、版本演进历史

### C++11 (2011) - 现代C++的里程碑

C++11是C++自1998年以来的第一次重大更新，被称为"Modern C++"的起点。这次更新引入了大量革命性的特性，彻底改变了C++的编程范式。

**主要特性：**
- 右值引用与移动语义
- Lambda表达式
- auto类型推导
- 智能指针
- 范围for循环
- constexpr
- noexcept
- nullptr
- 强类型枚举
- 统一初始化
- 变参模板
- 线程库

### C++14 (2014) - 细节优化

C++14主要是在C++11基础上的改进和补充，修复了一些问题，增加了一些便捷特性。

**主要特性：**
- 泛型lambda
- 函数返回类型推导
- relaxed constexpr
- 二进制字面量
- 数字分隔符
- 变量模板
- make_unique
- [[deprecated]]属性

### C++17 (2017) - 实用性提升

C++17继续推进现代化进程，增加了很多实用的特性，提高了开发效率。

**主要特性：**
- 结构化绑定
- if constexpr
- if switch初始化语句
- inline变量
- std::filesystem
- 折叠表达式
- std::optional, std::variant, std::any
- 并行算法
- 属性增强

### C++20 (2020) - 历史性更新

C++20是继C++11之后的又一次重大更新，引入了四大特性：概念、协程、模块、范围。

**主要特性：**
- Concepts（概念）
- Coroutines（协程）
- Modules（模块）
- Ranges（范围库）
- 三相比较运算符
- consteval, constinit
- 协程
- std::format
- span, jthread
- std::bit_cast
- 协程

### C++23 (2023) - 最新标准

C++23是最新发布的标准，继续完善和增强C++的功能。

**主要特性：**
- std::print/std::println
- 标准库模块
- Deducing this
- std::generator
- std::flat_map, std::flat_set
- std::mdspan
- std::expected
- 更多属性

### C++26 (预期特性)

目前C++26正在制定中，预计会包含：
- 静态反射
- 线程池
- std::execution
- 合约（可能推迟）

## 五、实践建议

### 代码示例
每个特性都应该通过实际代码来理解：

```cpp
// 1. 右值引用与移动语义
std::string str1 = "hello";
std::string str2 = std::move(str1);  // 移动

// 2. 智能指针
auto ptr = std::make_unique<int>(42);

// 3. Lambda
auto lambda = [](int x) { return x * 2; };

// 4. Concepts
template<typename T>
concept Integral = std::is_integral_v<T>;

// 5. 协程
generator<int> fibonacci() {
    int a = 0, b = 1;
    co_yield a;
    co_yield b;
    while (true) {
        int next = a + b;
        a = b;
        b = next;
        co_yield next;
    }
}
```

## 六、版本兼容性

### 向后兼容性
C++标准保持良好的向后兼容性，C++11、C++14、C++17、C++20、C++23的代码可以混用。

### 编译标志
- C++11: -std=c++11
- C++14: -std=c++14
- C++17: -std=c++17
- C++20: -std=c++20
- C++23: -std=c++23

### 特性检测
使用 `__has_feature` 或 `__cpp_*` 宏检测特性支持。

## 七、性能影响

### 零开销抽象
现代C++的设计原则是"零开销抽象"：
- 不使用时不产生开销
- 编译时优化
- 运行时效率等同手写代码

### 编译时计算
constexpr、模板元编程将运行时计算转移到编译时。

### 移动语义
避免不必要的拷贝，提升性能。

### 内联优化
Lambda、模板等容易内联优化。

## 八、总结

C++11-23的发展历程体现了现代C++的设计理念：
1. **安全性** - 智能指针、强类型、合约
2. **性能** - 移动语义、编译时计算、零开销
3. **可读性** - auto、结构化绑定、概念
4. **可维护性** - 模块、范围、算法
5. **生产率** - Lambda、格式化、工具库

掌握这些特性对于现代C++开发至关重要，也是面试的核心内容。后续章节将深入讲解每个特性的实现原理、应用场景和面试问题。
