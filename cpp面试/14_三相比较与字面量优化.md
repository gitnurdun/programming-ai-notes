# 三相比较与字面量优化 (C++20)

## 一、三相比较运算符（<=>）

### 1.1 基本用法

```cpp
// C++20: 三相比较运算符
class Point {
public:
    auto operator<=>(const Point&) const = default;
    
    int x, y;
};

// 自动生成所有比较运算符
Point p1{1, 2}, p2{3, 4};

bool result1 = p1 < p2;   // true
bool result2 = p1 <= p2;  // true
bool result3 = p1 > p2;   // false
bool result4 = p1 >= p2;  // false
bool result5 = p1 == p2;  // false
bool result6 = p1 != p2;  // true
```

### 1.2 返回类型

```cpp
// <=>返回比较类别
#include <compare>

class MyType {
public:
    // 返回strong_ordering
    std::strong_ordering operator<=>(const MyType&) const = default;
};

// 比较类别
// std::strong_ordering: 强排序，支持所有比较
// std::weak_ordering: 弱排序，不支持等价判断
// std::partial_ordering: 部分排序，可能无法比较
```

### 1.3 自定义比较

```cpp
class Person {
public:
    std::string name;
    int age;
    
    // 自定义三相比较
    auto operator<=>(const Person& other) const {
        if (auto cmp = age <=> other.age; cmp != 0) {
            return cmp;
        }
        return name <=> other.name;
    }
    
    // 需要单独定义==（C++20之前）
    bool operator==(const Person& other) const = default;
};
```

## 二、字面量优化

### 2.1 二进制字面量（C++14）

```cpp
// 二进制字面量
int bin1 = 0b1010;  // 10
int bin2 = 0B1111;  // 15

// 使用场景
unsigned int flags = 0b0001'0010'0100'1000;  // 设置多个标志位
```

### 2.2 数字分隔符（C++14）

```cpp
// 数字分隔符提高可读性
int million = 1'000'000;
double pi = 3.141'592'653'589'793;
int binary = 0b0001'0010'0100'1000;

// 使用场景
long long big_number = 9'223'372'036'854'775'807;
```

### 2.3 字符串字面量前缀

```cpp
// 字符串字面量前缀
const char* s1 = u8"Hello";       // UTF-8
const char16_t* s2 = u"Hello";    // UTF-16
const char32_t* s3 = U"Hello";    // UTF-32
const wchar_t* s4 = L"Hello";     // 宽字符
const char* s5 = R"(Hello\nWorld)";  // 原始字符串

// 原始字符串（多行）
const char* multi_line = R"(
This is a
multi-line
string
)";
```

### 2.4 自定义字面量（C++11）

```cpp
// 自定义字面量
constexpr long long operator"" _km(long double value) {
    return static_cast<long long>(value * 1000);
}

constexpr long long operator"" _m(long double value) {
    return static_cast<long long>(value);
}

constexpr long long operator"" _cm(long double value) {
    return static_cast<long long>(value / 100.0);
}

// 使用
auto distance = 5.5_km;  // 5500 meters
auto height = 180.0_cm;  // 1 meter
```

## 三、面试常见问题

### Q1: 三相比较运算符有什么优势？

**答案：**
1. 自动生成所有比较运算符
2. 减少代码重复
3. 保证一致性
4. 提高可维护性

### Q2: <=>的返回类型有哪些？

**答案：**
- std::strong_ordering: 强排序
- std::weak_ordering: 弱排序
- std::partial_ordering: 部分排序

### Q3: 数字分隔符有什么用途？

**答案：**
数字分隔符提高数字的可读性，特别是大数字。

### Q4: 如何定义自定义字面量？

**答案：**
```cpp
constexpr long long operator"" _suffix(long double value) {
    return static_cast<long long>(value);
}
```
