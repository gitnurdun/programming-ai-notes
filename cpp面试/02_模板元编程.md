# 模板元编程 (Template Metaprogramming)

## 一、模板元编程概述

### 1.1 什么是模板元编程

模板元编程（Template Metaprogramming, TMP）是利用C++模板系统在编译时进行计算的技术。它允许程序员在编译阶段生成和操作代码，而不是在运行时执行。

**核心思想：**
- 编译时计算（Compile-time computation）
- 类型作为第一类公民
- 递归模板实例化
- 零运行时开销

### 1.2 模板元编程的优势

**性能优势：**
- 零运行时开销：所有计算在编译时完成
- 代码优化：编译器可以深度优化生成的代码
- 类型安全：编译时类型检查

**灵活性：**
- 生成器模式：自动生成代码
- 策略模式：编译时选择策略
- 类型擦除：运行时多态的替代

### 1.3 模板元编程的应用场景

1. **类型计算**：类型萃取、类型转换
2. **数值计算**：编译时数学运算
3. **代码生成**：自动生成函数和类
4. **策略选择**：编译时选择最优算法
5. **容器设计**：静态容器、编译时大小

## 二、基础模板元编程

### 2.1 类型萃取（Type Traits）

类型萃取是模板元编程的基础，用于在编译时获取类型信息。

```cpp

    static constexpr bool value = true;

// 使用

static_assert(is_pointer<int>::value == false);
```

## 三、高级模板元编程技术

### 3.1 SFINAE原理

SFINAE（Substitution Failure Is Not An Error）是模板元编程的核心技术。

```cpp
// 检查类型是否有某个成员函数
template<typename T>
class HasBegin {
    template<typename U>
    static auto test(int) -> decltype(std::declval<U>().begin(), std::true_type{});
    
    template<typename>
    static std::false_type test(...);
    
public:
    static constexpr bool value = decltype(test<T>(0))::value;
};

// 使用
struct WithBegin {
    int* begin() { return nullptr; }
};

struct WithoutBegin {};

static_assert(HasBegin<WithBegin>::value == true);
static_assert(HasBegin<WithoutBegin>::value == false);
```

**std::enable_if 使用：**

```cpp
// 只对整数类型启用
template<typename T, typename = typename std::enable_if<std::is_integral_v<T>>::type>
T multiply(T a, T b) {
    return a * b;
}

// C++14: enable_if_t
template<typename T>
std::enable_if_t<std::is_integral_v<T>, T> multiply(T a, T b) {
    return a * b;
}

// C++17: if constexpr
template<typename T>
T multiply(T a, T b) {
    if constexpr (std::is_integral_v<T>) {
        return a * b;
    } else {
        return static_cast<T>(a * b);
    }
}
```

### 3.2 标签分发（Tag Dispatching）

```cpp
// 迭代器分类
struct input_iterator_tag {};
struct forward_iterator_tag {};
struct bidirectional_iterator_tag {};
struct random_access_iterator_tag {};

// 根据迭代器类型选择算法
template<typename Iterator>
void advance_impl(Iterator& it, int n, random_access_iterator_tag) {
    it += n;  // O(1)
}

template<typename Iterator>
void advance_impl(Iterator& it, int n, bidirectional_iterator_tag) {
    if (n > 0) {
        while (n--) ++it;
    } else {
        while (n++) --it;
    }
}

template<typename Iterator>
void advance_impl(Iterator& it, int n, input_iterator_tag) {
    while (n--) ++it;
}

// 主函数，根据迭代器类型分发
template<typename Iterator>
void advance(Iterator& it, int n) {
    using category = typename std::iterator_traits<Iterator>::iterator_category;
    advance_impl(it, n, category{});
}
```

```cpp
// 加锁策略
struct NoLock {
    void lock() {}
    void unlock() {}
};

struct MutexLock {
    std::mutex mtx;
    void lock() { mtx.lock(); }
    void unlock() { mtx.unlock(); }
};

// 通用容器，使用策略
template<typename T, typename LockPolicy = NoLock>
class ThreadSafeVector {
public:
    void push_back(const T& value) {
        lock_.lock();
        data_.push_back(value);
        lock_.unlock();
    }
    
    T& operator[](size_t index) {
        lock_.lock();
        T& result = data_[index];
        lock_.unlock();
        return result;
    }
    
private:
    std::vector<T> data_;
    LockPolicy lock_;
};

// 使用

ThreadSafeVector<int, MutexLock> vec2;         // 加锁版本
```

### 3.5 表达式模板（Expression Templates）

```cpp
// 延迟计算的表达式模板
template<typename L, typename R, typename Op>
class BinaryExpr {
public:
    BinaryExpr(const L& lhs, const R& rhs) 
        : lhs_(lhs), rhs_(rhs) {}
    
    auto operator[](size_t i) const {
        return Op::apply(lhs_[i], rhs_[i]);
    }
    
    size_t size() const {
        return lhs_.size();
    }
    
private:
    const L& lhs_;
    const R& rhs_;
};

// 加法操作
struct AddOp {
    template<typename T, typename U>
    static auto apply(T a, U b) {
        return a + b;
    }
};

// 矢量类
template<typename T>
class Vector {
public:
    Vector(size_t size) : data_(size) {}
    
    Vector(std::initializer_list<T> init) 
        : data_(init) {}
    
    template<typename Expr>
    Vector(const BinaryExpr<Expr, Expr, AddOp>& expr) {
        data_.resize(expr.size());
        for (size_t i = 0; i < size(); ++i) {
            data_[i] = expr[i];
        }
    }
    
    size_t size() const { return data_.size(); }
    T& operator[](size_t i) { return data_[i]; }
    const T& operator[](size_t i) const { return data_[i]; }
    
    // 表达式模板重载
    template<typename R>
    auto operator+(const R& rhs) const {
        return BinaryExpr<Vector, R, AddOp>(*this, rhs);
    }
    
private:
    std::vector<T> data_;
};

// 使用
Vector<int> v1 = {1, 2, 3, 4, 5};
Vector<int> v2 = {10, 20, 30, 40, 50};

// 延迟计算，避免临时对象
auto result = v1 + v2;  // 创建表达式对象，不立即计算
Vector<int> v3 = result;  // 在这里才真正计算
```

## 五、CRTP（奇异递归模板模式）

### 5.1 CRTP原理

CRTP（Curiously Recurring Template Pattern）是一种模板技术，派生类将自己作为模板参数传递给基类。

```cpp
// CRTP 基类
template<typename Derived>
class Base {
public:
    void interface() {
        static_cast<Derived*>(this)->implementation();
    }
    
    void interface2() {
        static_cast<Derived*>(this)->implementation2();
    }
};

// 派生类
class Derived : public Base<Derived> {
public:
    void implementation() {
        std::cout << "Derived implementation" << std::endl;
    }
    
    void implementation2() {
        std::cout << "Derived implementation2" << std::endl;
    }
};

// 使用
Derived d;
d.interface();  // 调用 Derived::implementation
```

### 5.2 CRTP应用

**静态多态：**

```cpp
template<typename Derived>
class Shape {
public:
    void draw() {
        static_cast<Derived*>(this)->draw_impl();
    }
    
    double area() {
        return static_cast<Derived*>(this)->area_impl();
    }
};

class Circle : public Shape<Circle> {
public:
    Circle(double radius) : radius_(radius) {}
    
    void draw_impl() {
        std::cout << "Drawing circle with radius " << radius_ << std::endl;
    }
    
    double area_impl() {
        return 3.14159 * radius_ * radius_;
    }
    
private:
    double radius_;
};

class Rectangle : public Shape<Rectangle> {
public:
    Rectangle(double width, double height) 
        : width_(width), height_(height) {}
    
    void draw_impl() {
        std::cout << "Drawing rectangle " << width_ << "x" << height_ << std::endl;
    }
    
    double area_impl() {
        return width_ * height_;
    }
    
private:
    double width_, height_;
};

// 使用
Circle c(5.0);
Rectangle r(3.0, 4.0);

c.draw();   // 静态调用，无虚函数开销
r.draw();

std::cout << "Circle area: " << c.area() << std::endl;
std::cout << "Rectangle area: " << r.area() << std::endl;
```

### 6.2 编译时矩阵

```cpp
// 编译时矩阵
template<size_t Rows, size_t Cols, typename T = double>
class Matrix {
public:
    using value_type = T;
    
    Matrix() : data_{} {}
    
    T& operator()(size_t row, size_t col) {
        return data_[row][col];
    }
    
    const T& operator()(size_t row, size_t col) const {
        return data_[row][col];
    }
    
    static constexpr size_t rows() { return Rows; }
    static constexpr size_t cols() { return Cols; }
    
private:
    T data_[Rows][Cols];
};

// 矩阵乘法（编译时检查维度）
template<size_t R1, size_t C1, size_t R2, size_t C2, typename T>
Matrix<R1, C2, T> operator*(const Matrix<R1, C1, T>& a, 
                            const Matrix<R2, C2, T>& b) {
    static_assert(C1 == R2, "Matrix dimensions don't match for multiplication");
    
    Matrix<R1, C2, T> result;
    for (size_t i = 0; i < R1; ++i) {
        for (size_t j = 0; j < C2; ++j) {
            result(i, j) = 0;
            for (size_t k = 0; k < C1; ++k) {
                result(i, j) += a(i, k) * b(k, j);
            }
        }
    }
    return result;
}

// 使用
Matrix<2, 3> m1;
Matrix<3, 2> m2;
Matrix<2, 2> m3 = m1 * m2;  // 编译时检查维度
```

## 七、性能考虑

### 7.1 编译时开销

模板元编程会增加编译时间：
- **实例化开销**：每个模板实例都需要编译
- **代码膨胀**：可能生成大量重复代码
- **符号膨胀**：增加调试符号大小

**优化策略：**
```cpp
// 使用 if constexpr 减少实例化
template<typename T>
void process(T value) {
    if constexpr (std::is_arithmetic_v<T>) {
        // 只为算术类型生成这段代码
    }
}

// 使用 extern template 避免重复实例化
extern template class Vector<int>;  // 声明
template class Vector<int>;         // 在一个文件中实例化
```

### 7.2 运行时开销

模板元编程本身零运行时开销，但需要注意：
```cpp
// 模板递归深度限制
template<int N>
struct Recursion {
    static constexpr int value = Recursion<N - 1>::value;
};

// 需要设置递归深度

```

### 7.3 代码大小优化

```cpp
// 使用内联优化
template<typename T>
constexpr T max(T a, T b) {
    return a > b ? a : b;
}

// 编译器会内联这个函数，无运行时开销
```

### Q1: 什么是模板元编程？它有什么优势？

**答案：**
模板元编程是利用C++模板系统在编译时进行计算的技术。

**优势：**
1. **零运行时开销**：所有计算在编译时完成
2. **类型安全**：编译时类型检查
3. **代码优化**：编译器可以深度优化
4. **灵活性**：可以在编译时选择最优实现

### Q2: 解释 SFINAE 的原理和应用

**答案：**
SFINAE（Substitution Failure Is Not An Error）是模板参数替换失败不是错误的机制。

**原理：**
在模板参数推导时，如果某种替换导致无效代码，编译器不会报错，而是丢弃这个候选模板。

**应用：**
1. 重载决议：根据类型特征选择不同的重载
2. 类型检查：检测类型是否有特定成员
3. 条件编译：根据类型特征启用/禁用某些功能

```cpp
template<typename T>
auto test(int) -> decltype(std::declval<T>().begin(), std::true_type{});

template<typename>
auto test(...) -> std::false_type;

template<typename T>
struct HasBegin {
    static constexpr bool value = decltype(test<T>(0))::value;
};
```

### Q3: 什么是 CRTP？它有什么用途？

**答案：**
CRTP（Curiously Recurring Template Pattern）是一种模板技术，派生类将自己作为模板参数传递给基类。

**用途：**
1. **静态多态**：避免虚函数的运行时开销
2. **代码复用**：在基类中实现通用逻辑
3. **操作符重载**：统一实现操作符
4. **单例模式**：类型安全的单例实现

```cpp
template<typename Derived>
class Base {
public:
    void interface() {
        static_cast<Derived*>(this)->implementation();
    }
};

class Derived : public Base<Derived> {
public:
    void implementation() { /* ... */ }
};
```

### Q4: 如何实现类型萃取？

**答案：**
类型萃取通过模板特化实现：

```cpp
// 基础模板
template<typename T>
struct is_pointer {
    static constexpr bool value = false;
};

// 特化版本
template<typename T>
struct is_pointer<T*> {
    static constexpr bool value = true;
};

// 使用 constexpr 变量模板（C++14）
template<typename T>
constexpr bool is_pointer_v = is_pointer<T>::value;
```

### Q5: 什么是表达式模板？它解决了什么问题？

**答案：**
表达式模板是一种延迟计算技术，将表达式表示为类型而不是立即计算。

**解决的问题：**
1. **临时对象**：避免创建不必要的临时对象
2. **循环展开**：在赋值时一次性计算整个表达式
3. **性能优化**：减少内存访问和拷贝

```cpp
// v1 + v2 + v3 不会创建临时对象
// 只在赋值时才真正计算
auto result = v1 + v2 + v3;
```

### Q6: 解释折叠表达式的用法

**答案：**
折叠表达式用于展开参数包：

```cpp
// 右折叠
template<typename... Args>
auto sum(Args... args) {
    return (args + ...);  // (((arg1 + arg2) + arg3) + ...)
}

// 左折叠
template<typename... Args>
auto sum_left(Args... args) {
    return (... + args);  // (arg1 + (arg2 + (arg3 + ...)))
}

// 逻辑折叠
template<typename... Args>
bool all_true(Args... args) {
    return (args && ...);
}
```

### Q7: 如何实现编译时字符串？

**答案：**
```cpp
template<size_t N>
struct FixedString {
    constexpr FixedString(const char (&str)[N]) {
        std::copy_n(str, N, data);
    }
    
    char data[N];
};

template<FixedString Str>
struct Message {
    static constexpr const char* value = Str.data;
};

constexpr auto hello = FixedString("Hello");
Message<hello> msg;
```

### Q8: 标签分发是什么？有什么用途？

**答案：**
标签分发是根据类型特征选择不同实现的技术。

**用途：**
1. **算法优化**：根据迭代器类型选择最优算法
2. **特化处理**：为特定类型提供特殊实现
3. **性能优化**：避免运行时检查

```cpp
template<typename Iterator>
void advance(Iterator& it, int n) {
    using category = typename std::iterator_traits<Iterator>::iterator_category;
    advance_impl(it, n, category{});
}
```

### Q9: 模板元编程有什么缺点？

**答案：**
1. **编译时间**：增加编译时间
2. **代码膨胀**：可能生成大量重复代码
3. **调试困难**：错误信息难以理解
4. **学习曲线**：语法复杂，难以掌握
5. **递归限制**：编译器对递归深度有限制

### Q10: 如何优化模板元编程的编译时间？

**答案：**
1. **减少实例化**：使用 `if constexpr` 减少不必要的实例化
2. **extern template**：避免重复实例化
3. **类型别名**：使用 using 简化类型
4. **预编译头**：使用预编译头文件
5. **模块化**：将模板拆分为多个文件
