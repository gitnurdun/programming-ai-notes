# 并行并发编程 (C++11-20)

## 一、并发编程概述

### 1.1 并发与并行的区别

**并发（Concurrency）**：
- 多个任务在同一时间段内交替执行
- 单核CPU通过时间片轮转实现
- 任务看起来同时执行，实际是交替进行

**并行（Parallelism）**：
- 多个任务在同一时刻真正同时执行
- 需要多核CPU支持
- 任务真正同时执行

```cpp
// 并发：单核CPU，任务交替执行
Thread1: A -> B -> C
Thread2:      X -> Y -> Z

// 并行：多核CPU，任务同时执行
Core1: A -> B -> C
Core2: X -> Y -> Z
```

### 1.2 C++并发编程历史

| 版本 | 新特性 |
|------|--------|
| C++11 | 线程库、互斥量、条件变量、原子操作、future/promise |
| C++14 | 共享 timed mutex、shared_mutex |
| C++17 | 并行算法、string_view、optional |
| C++20 | jthread、latch、barrier、semaphore、stop_token |

## 二、线程（std::thread）

### 2.1 基本用法

```cpp
#include <thread>
#include <iostream>

// 基本线程创建
void hello() {
    std::cout << "Hello from thread!" << std::endl;
}

int main() {
    std::thread t(hello);  // 创建线程
    t.join();              // 等待线程结束
    
    return 0;
}

// 带参数的线程
void print_message(const std::string& msg, int count) {
    for (int i = 0; i < count; ++i) {
        std::cout << msg << std::endl;
    }
}

int main() {
    std::thread t(print_message, "Hello", 3);
    t.join();
    return 0;
}
```

### 2.2 线程的生命周期

```cpp
#include <thread>
#include <chrono>

void worker() {
    std::cout << "Worker started" << std::endl;
    std::this_thread::sleep_for(std::chrono::seconds(2));
    std::cout << "Worker finished" << std::endl;
}

int main() {
    std::cout << "Main: Creating thread" << std::endl;
    std::thread t(worker);
    
    std::cout << "Main: Doing other work" << std::endl;
    std::this_thread::sleep_for(std::chrono::seconds(1));
    
    std::cout << "Main: Waiting for thread" << std::endl;
    t.join();  // 等待线程结束
    
    std::cout << "Main: Thread finished" << std::endl;
    return 0;
}
```

### 2.3 detach vs join

```cpp
// join: 等待线程结束
std::thread t(worker);
t.join();  // 主线程等待t结束

// detach: 分离线程，不等待
std::thread t2(worker);
t2.detach();  // t2在后台运行，主线程不等待

// joinable检查
std::thread t3(worker);
if (t3.joinable()) {
    t3.join();
}

// 注意：析构函数会检查
// 如果线程是joinable的，会调用std::terminate
// 必须在析构前调用join或detach
```

### 2.4 线程参数传递


## 三、互斥量（Mutex）

### 3.1 std::mutex

```cpp
#include <mutex>
#include <thread>
#include <iostream>

int counter = 0;
std::mutex mtx;

void increment() {
    for (int i = 0; i < 10000; ++i) {
        std::lock_guard<std::mutex> lock(mtx);  // 自动加锁和解锁
        ++counter;
    }
}

int main() {
    std::thread t1(increment);
    std::thread t2(increment);
    
    t1.join();
    t2.join();
    
    std::cout << "Counter: " << counter << std::endl;  // 20000
    return 0;
}
```

### 3.2 std::lock_guard

```cpp
// RAII风格的互斥量
std::mutex mtx;

void critical_section() {
    std::lock_guard<std::mutex> lock(mtx);  // 构造时加锁
    // 临界区代码
    // 析构时自动解锁
}

// 等价于
void critical_section_manual() {
    mtx.lock();
    try {
        // 临界区代码
    } catch (...) {
        mtx.unlock();
        throw;
    }
    mtx.unlock();
}
```

### 3.3 std::unique_lock

```cpp
#include <mutex>

// 更灵活的锁
std::mutex mtx;

void flexible_lock() {
    std::unique_lock<std::mutex> lock(mtx);  // 加锁
    
    // 可以手动解锁
    lock.unlock();
    
    // 可以重新加锁
    lock.lock();
    
    // 可以尝试加锁
    if (lock.try_lock()) {
        // 加锁成功
    }
    
    // 可以延迟加锁
    std::unique_lock<std::mutex> lock2(mtx, std::defer_lock);
    // ... 其他操作
    lock2.lock();  // 稍后加锁
}
```

### 3.4 std::shared_mutex (C++17)

```cpp
#include <shared_mutex>
#include <thread>
#include <vector>

std::shared_mutex shared_mtx;
std::vector<int> data;

void read_data(int id) {
    std::shared_lock<std::shared_mutex> lock(shared_mtx);  // 共享锁
    std::cout << "Reader " << id << ": ";
    for (int val : data) {
        std::cout << val << " ";
    }
    std::cout << std::endl;
}

void write_data(int value) {
    std::unique_lock<std::shared_mutex> lock(shared_mtx);  // 独占锁
    data.push_back(value);
    std::cout << "Writer: Added " << value << std::endl;
}

int main() {
    std::thread writer1(write_data, 1);
    std::thread writer2(write_data, 2);
    
    std::thread reader1(read_data, 1);
    std::thread reader2(read_data, 2);
    
    writer1.join();
    writer2.join();
    reader1.join();
    reader2.join();
    
    return 0;
}
```

### 3.5 std::scoped_lock (C++17)

```cpp
#include <mutex>

// 一次性锁定多个互斥量，避免死锁
std::mutex mtx1, mtx2, mtx3;

void multi_lock() {
    std::scoped_lock lock(mtx1, mtx2, mtx3);  // 同时锁定所有互斥量
    // 临界区代码
    // 析构时自动解锁所有互斥量
}

// 等价于（但更安全）
void multi_lock_manual() {
    std::lock(mtx1, mtx2, mtx3);  // 使用std::lock避免死锁
    std::lock_guard<std::mutex> lock1(mtx1, std::adopt_lock);
    std::lock_guard<std::mutex> lock2(mtx2, std::adopt_lock);
    std::lock_guard<std::mutex> lock3(mtx3, std::adopt_lock);
}
```

## 四、条件变量（Condition Variable）

### 4.1 基本用法

```cpp
#include <condition_variable>
#include <mutex>
#include <thread>
#include <queue>

std::queue<int> data_queue;
std::mutex mtx;
std::condition_variable cv;
bool done = false;

void producer() {
    for (int i = 0; i < 10; ++i) {
        {
            std::lock_guard<std::mutex> lock(mtx);
            data_queue.push(i);
            std::cout << "Produced: " << i << std::endl;
        }
        cv.notify_one();  // 通知一个等待的线程
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
    }
    
    {
        std::lock_guard<std::mutex> lock(mtx);
        done = true;
    }
    cv.notify_all();  // 通知所有等待的线程
}

void consumer() {
    while (true) {
        std::unique_lock<std::mutex> lock(mtx);
        cv.wait(lock, [] { return !data_queue.empty() || done; });  // 等待条件
        
        if (data_queue.empty() && done) {
            break;
        }
        
        int value = data_queue.front();
        data_queue.pop();
        std::cout << "Consumed: " << value << std::endl;
    }
}

int main() {
    std::thread p(producer);
    std::thread c(consumer);
    
    p.join();
    c.join();
    
    return 0;
}
```

### 4.2 条件变量的工作原理

```cpp
// wait函数的内部实现
template<typename Predicate>
void wait(std::unique_lock<std::mutex>& lock, Predicate pred) {
    while (!pred()) {
        // 1. 解锁互斥量
        lock.unlock();
        
        // 2. 等待通知
        // 线程进入等待状态
        
        // 3. 被唤醒后重新加锁
        lock.lock();
    }
}

// 使用示例
std::condition_variable cv;
std::mutex mtx;
bool ready = false;

void worker() {
    std::unique_lock<std::mutex> lock(mtx);
    cv.wait(lock, [] { return ready; });  // 等待ready为true
    // 执行工作
}
```

## 五、原子操作（std::atomic）

### 5.1 基本用法

```cpp
#include <atomic>
#include <thread>
#include <iostream>

std::atomic<int> counter(0);

void increment() {
    for (int i = 0; i < 10000; ++i) {
        counter.fetch_add(1, std::memory_order_relaxed);  // 原子加法
    }
}

int main() {
    std::thread t1(increment);
    std::thread t2(increment);
    
    t1.join();
    t2.join();
    
    std::cout << "Counter: " << counter << std::endl;  // 20000
    return 0;
}
```

### 5.2 内存序（Memory Order）

```cpp
// 内存序类型
// 1. memory_order_relaxed: 最松散，只保证原子性
std::atomic<int> x;
x.store(1, std::memory_order_relaxed);

// 2. memory_order_consume: 依赖顺序
// 3. memory_order_acquire: 获取操作
// 4. memory_order_release: 释放操作
// 5. memory_order_acq_rel: 获取+释放
// 6. memory_order_seq_cst: 顺序一致性（默认）

// 示例
std::atomic<bool> ready(false);
int data = 0;

void producer() {
    data = 42;
    ready.store(true, std::memory_order_release);  // 释放操作
}

void consumer() {
    while (!ready.load(std::memory_order_acquire)) {  // 获取操作
        // 等待
    }
    std::cout << data << std::endl;  // 保证看到data的修改
}
```

### 5.3 原子指针

```cpp
std::atomic<int*> ptr(nullptr);

void thread1() {
    int* p = new int(42);
    ptr.store(p, std::memory_order_release);
}

void thread2() {
    int* p = nullptr;
    while (!(p = ptr.load(std::memory_order_acquire))) {
        // 等待
    }
    std::cout << *p << std::endl;
    delete p;
}
```

## 六、Future和Promise

### 6.1 std::promise

```cpp
#include <future>
#include <thread>
#include <iostream>

void calculate(std::promise<int> prom) {
    try {
        int result = 42;
        prom.set_value(result);  // 设置值
    } catch (...) {
        prom.set_exception(std::current_exception());  // 设置异常
    }
}

int main() {
    std::promise<int> prom;
    std::future<int> fut = prom.get_future();  // 获取future
    
    std::thread t(calculate, std::move(prom));
    
    try {
        int result = fut.get();  // 获取值，阻塞直到设置
        std::cout << "Result: " << result << std::endl;
    } catch (const std::exception& e) {
        std::cout << "Exception: " << e.what() << std::endl;
    }
    
    t.join();
    return 0;
}
```

### 7.2 std::latch

```cpp
#include <latch>

#include <vector>

void worker(int id, std::latch& done) {
    std::cout << "Worker " << id << " working..." << std::endl;

    return 0;
}
```

## 九、线程池

### 9.1 简单线程池实现

```cpp
#include <thread>
#include <queue>
#include <mutex>
#include <condition_variable>
#include <functional>
#include <vector>

class ThreadPool {
public:
    ThreadPool(size_t num_threads) : stop(false) {
        for (size_t i = 0; i < num_threads; ++i) {
            workers.emplace_back([this] {
                for (;;) {
                    std::function<void()> task;
                    {
                        std::unique_lock<std::mutex> lock(mtx);
                        cv.wait(lock, [this] { 
                            return stop || !tasks.empty(); 
                        });
                        
                        if (stop && tasks.empty()) {
                            return;
                        }
                        
                        task = std::move(tasks.front());
                        tasks.pop();
                    }
                    task();
                }
            });
        }
    }
    
    template<typename F>
    void enqueue(F&& f) {
        {
            std::unique_lock<std::mutex> lock(mtx);
            tasks.emplace(std::forward<F>(f));
        }
        cv.notify_one();
    }
    
    ~ThreadPool() {
        {
            std::unique_lock<std::mutex> lock(mtx);
            stop = true;
        }
        cv.notify_all();
        for (auto& worker : workers) {
            worker.join();
        }
    }
    
private:
    std::vector<std::thread> workers;
    std::queue<std::function<void()>> tasks;
    std::mutex mtx;
    std::condition_variable cv;
    bool stop;
};

// 使用
int main() {
    ThreadPool pool(4);
    
    for (int i = 0; i < 10; ++i) {
        pool.enqueue([i] {
            std::cout << "Task " << i << std::endl;
        });
    }
    
    return 0;
}
```

## 十、面试常见问题

### Q1: 线程和进程有什么区别？

**答案：**
| 特性 | 线程 | 进程 |
|------|------|------|
| 内存 | 共享地址空间 | 独立地址空间 |
| 通信 | 共享内存、全局变量 | IPC（管道、消息队列等） |
| 创建开销 | 小 | 大 |
| 上下文切换 | 快 | 慢 |
| 数据共享 | 容易 | 困难 |

### Q2: 什么是竞态条件？如何避免？

**答案：**
竞态条件是指多个线程同时访问和修改共享数据，导致结果依赖于线程执行顺序。

**避免方法：**
1. 使用互斥量（mutex）保护共享数据
2. 使用原子操作
3. 使用线程安全的数据结构
4. 设计无锁算法

### Q3: 什么是死锁？如何避免？

**答案：**
死锁是指两个或多个线程互相等待对方释放资源，导致所有线程都无法继续执行。

**避免方法：**
1. 固定加锁顺序
2. 使用std::lock同时锁定多个互斥量
3. 使用try_lock避免阻塞
4. 设置超时
5. 使用std::scoped_lock（C++17）

### Q4: lock_guard和unique_lock有什么区别？

**答案：**
- **lock_guard**：简单、轻量，只能构造时加锁，析构时解锁
- **unique_lock**：更灵活，支持手动加锁/解锁、延迟加锁、尝试加锁

```cpp
std::lock_guard<std::mutex> lock(mtx);  // 简单

std::unique_lock<std::mutex> lock(mtx);  // 灵活
lock.unlock();
lock.lock();
```

### Q5: 什么是条件变量？如何使用？

**答案：**
条件变量用于线程间同步，允许线程等待某个条件成立。

**使用示例：**
```cpp
std::condition_variable cv;
std::mutex mtx;
bool ready = false;

void producer() {
    std::lock_guard<std::mutex> lock(mtx);
    ready = true;
    cv.notify_one();  // 通知消费者
}

void consumer() {
    std::unique_lock<std::mutex> lock(mtx);
    cv.wait(lock, [] { return ready; });  // 等待条件
}
```

### Q6: 原子操作的内存序有哪些？

**答案：**
1. **memory_order_relaxed**：最松散，只保证原子性
2. **memory_order_consume**：依赖顺序
3. **memory_order_acquire**：获取操作
4. **memory_order_release**：释放操作
5. **memory_order_acq_rel**：获取+释放
6. **memory_order_seq_cst**：顺序一致性（默认）

### Q7: 什么是future和promise？

**答案：**
- **promise**：生产者，用于设置值或异常
- **future**：消费者，用于获取值或异常

它们用于线程间传递结果，支持异步操作。

### Q8: C++20引入了哪些并发新特性？

**答案：**
1. **std::jthread**：自动join的线程，支持停止请求
2. **std::latch**：线程同步屏障
3. **std::barrier**：可重复使用的同步屏障
4. **std::semaphore**：计数信号量
5. **std::stop_token**：停止令牌

## 十一、最佳实践

### 11.1 优先使用高级抽象

```cpp
// 好的实践：使用高级抽象
std::lock_guard<std::mutex> lock(mtx);
std::async(std::launch::async, func);

// 避免：底层操作
mtx.lock();
// ...
mtx.unlock();
```

### 11.2 避免数据竞争

```cpp
// 好的实践：使用互斥量保护共享数据
std::mutex mtx;
int shared_data;

void thread_func() {
    std::lock_guard<std::mutex> lock(mtx);
    ++shared_data;
}

// 避免：无保护访问
// void thread_func() {
//     ++shared_data;  // 数据竞争！
// }
```

### 11.3 最小化临界区

```cpp
// 好的实践：最小化临界区
std::lock_guard<std::mutex> lock(mtx);
int value = shared_data;
lock.~lock_guard();  // 手动解锁（不推荐，使用unique_lock）

// 进行耗时操作...

// 更好的做法
{
    std::lock_guard<std::mutex> lock(mtx);
    int value = shared_data;
}
// 进行耗时操作...
```

### 11.4 使用RAII管理资源

```cpp
// 好的实践：使用RAII
std::lock_guard<std::mutex> lock(mtx);

// 避免：手动管理
mtx.lock();
// ...
mtx.unlock();
```
