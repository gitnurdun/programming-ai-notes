# 数据对齐与属性说明符 (C++11-20)

## 一、数据对齐

### 1.1 alignas

```cpp
// alignas指定对齐要求
alignas(16) int x;  // 16字节对齐

struct alignas(32) AlignedStruct {
    int a;
    double b;
    char c;
};

// 使用
static_assert(alignof(AlignedStruct) == 32);
```

### 1.2 alignof

```cpp
// alignof查询对齐要求
std::cout << alignof(int) << std::endl;        // 4
std::cout << alignof(double) << std::endl;     // 8
std::cout << alignof(std::max_align_t) << std::endl;  // 最大对齐

struct MyStruct {
    char a;
    int b;
    double c;
};

std::cout << alignof(MyStruct) << std::endl;  // 8
```

### 1.3 std::aligned_storage

```cpp
// 对齐存储
template<typename T, size_t N>
class Buffer {
    using Storage = typename std::aligned_storage<sizeof(T), alignof(T)>::type;
    
    Storage data_[N];
    
public:
    T& operator[](size_t i) {
        return *reinterpret_cast<T*>(&data_[i]);
    }
};
```

## 二、属性说明符

### 2.1 标准属性

```cpp
// [[noreturn]]: 函数不返回
[[noreturn]] void fatal_error() {
    std::abort();
}

// [[deprecated]]: 标记为已弃用
[[deprecated("Use new_function instead")]]
void old_function() {}

// C++14
[[deprecated]] void old_function2() {}

// [[nodiscard]]: 必须检查返回值
[[nodiscard]] int calculate() {
    return 42;
}

// int result = calculate();  // 警告：必须检查返回值
calculate();  // 警告：忽略返回值

// [[maybe_unused]]: 可能未使用
void func([[maybe_unused]] int param) {
    // param可能未使用
}

// [[fallthrough]]: 故意fallthrough
switch (value) {
    case 1:
        do_something();
        [[fallthrough]];  // 故意fallthrough
    case 2:
        do_more();
        break;
}
```

### 2.2 C++20新属性

```cpp
// [[likely]]: 可能性高
if (condition) [[likely]] {
    // 高概率执行
} else [[unlikely]] {
    // 低概率执行
}

// [[no_unique_address]]: 空基类优化
struct Empty {};

struct A {
    int x;
    [[no_unique_address]] Empty e;
};

static_assert(sizeof(A) == sizeof(int));  // 空基类不占用空间
```

### 2.3 非标准属性

```cpp
// GCC/Clang属性
__attribute__((always_inline)) void inline_func() {}

// MSVC属性
__declspec(dllexport) void exported_function() {}

// 跨平台
#if defined(__GNUC__) || defined(__clang__)
    #define EXPORT __attribute__((visibility("default")))
#elif defined(_MSC_VER)
    #define EXPORT __declspec(dllexport)
#endif

EXPORT void cross_platform_function() {}
```

## 三、面试常见问题

### Q1: alignas有什么用途？

**答案：**
alignas用于指定类型或变量的对齐要求，优化内存访问性能。

### Q2: alignof有什么用途？

**答案：**
alignof用于查询类型的对齐要求。

### Q3: [[nodiscard]]的作用是什么？

**答案：**
[[nodiscard]]标记函数返回值必须被检查，避免忽略错误。

### Q4: [[deprecated]]的作用是什么？

**答案：**
[[deprecated]]标记函数或变量为已弃用，提供迁移信息。

### Q5: [[likely]]和[[unlikely]]有什么用途？

**答案：**
帮助编译器优化分支预测，提高性能。

## 四、最佳实践

### 4.1 使用alignas优化性能

```cpp
alignas(64) int cache_line[16];  // 缓存行对齐
```

### 4.2 使用nodiscard标记重要返回值

```cpp
[[nodiscard]] int calculate_result();
```

### 4.3 使用deprecated标记旧接口

```cpp
[[deprecated("Use new_api instead")]] void old_api();
```

### 4.4 使用likely/unlikely优化分支

```cpp
if (likely_condition) [[likely]] {
    // 高概率路径
}
```
