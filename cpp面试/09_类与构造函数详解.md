# 类与构造函数详解 (C++11-20)

## 一、类的特殊成员函数

### 1.1 特殊成员函数概览

C++类有以下特殊成员函数：

| 特殊成员函数 | 默认生成条件 | 说明 |
|-------------|-------------|------|
| 默认构造函数 | 未声明任何构造函数 | 无参构造 |
| 析构函数 | 未声明析构函数 | 释放资源 |
| 拷贝构造函数 | 未声明移动操作 | 深拷贝 |
| 拷贝赋值运算符 | 未声明移动操作 | 深拷贝 |
| 移动构造函数 | 未声明拷贝操作 | 移动资源 |
| 移动赋值运算符 | 未声明拷贝操作 | 移动资源 |

### 1.2 五法则（Rule of Five）

C++11引入移动语义后，五法则替代了三法则：

```cpp
class MyClass {
public:
    // 1. 析构函数
    ~MyClass() {
        delete[] data_;
    }
    
    // 2. 拷贝构造函数
    MyClass(const MyClass& other) 
        : size_(other.size_) 
        , data_(new int[other.size_]) {
        std::copy(other.data_, other.data_ + size_, data_);
    }
    
    // 3. 拷贝赋值运算符
    MyClass& operator=(const MyClass& other) {
        if (this != &other) {
            delete[] data_;
            size_ = other.size_;
            data_ = new int[size_];
            std::copy(other.data_, other.data_ + size_, data_);
        }
        return *this;
    }
    
    // 4. 移动构造函数
    MyClass(MyClass&& other) noexcept
        : size_(other.size_)
        , data_(other.data_) {
        other.size_ = 0;
        other.data_ = nullptr;
    }
    
    // 5. 移动赋值运算符
    MyClass& operator=(MyClass&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            size_ = other.size_;
            data_ = other.data_;
            other.size_ = 0;
            other.data_ = nullptr;
        }
        return *this;
    }
    
private:
    int* data_;
    size_t size_;
};
```

## 二、构造函数详解

### 2.1 默认构造函数

```cpp
class MyClass {
public:
    // 默认构造函数
    MyClass() : value_(0) {
        std::cout << "Default constructor" << std::endl;
    }
    
    // C++11: 显式请求默认构造函数
    MyClass() = default;
    
    // C++11: 禁止默认构造函数
    MyClass() = delete;
    
private:
    int value_;
};

// 使用
MyClass obj1;       // 调用默认构造函数
MyClass obj2{};      // C++11统一初始化
MyClass obj3 = MyClass();  // 拷贝初始化（可能被优化）
```

### 2.2 委托构造函数 (C++11)

```cpp
class MyClass {
public:
    // 委托构造函数
    MyClass(int x, int y, int z) 
        : x_(x), y_(y), z_(z) {
        std::cout << "Three parameters" << std::endl;
    }
    
    // 委托给上面的构造函数
    MyClass(int x, int y) : MyClass(x, y, 0) {
        std::cout << "Two parameters" << std::endl;
    }
    
    // 委托给上面的构造函数
    MyClass(int x) : MyClass(x, 0, 0) {
        std::cout << "One parameter" << std::endl;
    }
    
    // 委托给上面的构造函数
    MyClass() : MyClass(0, 0, 0) {
        std::cout << "No parameters" << std::endl;
    }
    
private:
    int x_, y_, z_;
};

// 使用
MyClass obj1;        // 输出: Three parameters, No parameters
MyClass obj2(1);     // 输出: Three parameters, One parameter
MyClass obj3(1, 2);  // 输出: Three parameters, Two parameters
MyClass obj4(1, 2, 3); // 输出: Three parameters
```

### 2.3 继承构造函数 (C++11)

```cpp
class Base {
public:
    Base(int x) : value_(x) {}
    Base(int x, int y) : value_(x + y) {}
    Base(const std::string& str) : value_(std::stoi(str)) {}
    
protected:
    int value_;
};

class Derived : public Base {
public:
    // 继承Base的所有构造函数
    using Base::Base;
    
    // 可以添加自己的构造函数
    Derived() : Base(0) {
        std::cout << "Derived default constructor" << std::endl;
    }
    
    void print() {
        std::cout << "Value: " << value_ << std::endl;
    }
};

// 使用
Derived d1(10);               // 使用Base(int)
Derived d2(10, 20);           // 使用Base(int, int)
Derived d3("42");             // 使用Base(const std::string&)
Derived d4;                   // 使用Derived()
```

### 2.4 类内成员初始化器 (C++11)

```cpp
class MyClass {
public:
    // 使用类内成员初始化器
    MyClass() {
        // value1_和value2_已经初始化
    }
    
    MyClass(int x) : value2_(x) {
        // value1_使用类内初始化器，value2_使用成员初始化列表
    }
    
private:
    int value1_ = 10;        // 类内成员初始化器
    int value2_ = 20;
    std::string str_ = "Hello";
    std::vector<int> vec_ = {1, 2, 3};
};

// 优势
// 1. 减少构造函数重复代码
// 2. 清晰表达默认值
// 3. 支持非静态成员的默认值
```

### 2.5 初始化顺序

```cpp
class MyClass {
public:
    MyClass(int x) : value2_(x), value1_(value2_) {
        // 警告：value1_在value2_之前初始化
        // 所以value1_会使用未初始化的value2_
    }
    
private:
    int value1_;  // 先初始化
    int value2_;  // 后初始化
};

// 正确做法：按声明顺序初始化
class MyClass {
public:
    MyClass(int x) : value1_(x), value2_(value1_) {
        // 正确：value1_先初始化
    }
    
private:
    int value1_;  // 先初始化
    int value2_;  // 后初始化
};
```

## 三、拷贝控制

### 3.1 拷贝构造函数

```cpp
class MyClass {
public:
    // 拷贝构造函数
    MyClass(const MyClass& other) 
        : data_(new int[other.size_])
        , size_(other.size_) {
        std::copy(other.data_, other.data_ + size_, data_);
        std::cout << "Copy constructor" << std::endl;
    }
    
    // C++11: 显式请求默认拷贝构造函数
    MyClass(const MyClass&) = default;
    
    // C++11: 禁止拷贝
    MyClass(const MyClass&) = delete;
    
private:
    int* data_;
    size_t size_;
};

// 调用时机
MyClass obj1;
MyClass obj2 = obj1;      // 拷贝构造
MyClass obj3(obj1);       // 拷贝构造
void func(MyClass obj);   // 拷贝构造
MyClass obj4 = func(obj1); // 拷贝构造（可能被优化）
```

### 3.2 拷贝赋值运算符

```cpp
class MyClass {
public:
    // 拷贝赋值运算符
    MyClass& operator=(const MyClass& other) {
        if (this != &other) {
            // 1. 释放当前资源
            delete[] data_;
            
            // 2. 分配新资源
            size_ = other.size_;
            data_ = new int[size_];
            
            // 3. 拷贝数据
            std::copy(other.data_, other.data_ + size_, data_);
        }
        std::cout << "Copy assignment" << std::endl;
        return *this;
    }
    
    // 使用copy-and-swap惯用法（异常安全）
    MyClass& operator=(MyClass other) {  // 按值传递，会调用拷贝构造
        swap(*this, other);  // 交换资源
        return *this;
    }
    
    friend void swap(MyClass& a, MyClass& b) noexcept {
        std::swap(a.data_, b.data_);
        std::swap(a.size_, b.size_);
    }
    
private:
    int* data_;
    size_t size_;
};

// 调用时机
MyClass obj1, obj2;
obj2 = obj1;  // 拷贝赋值
obj1 = obj1;  // 自赋值
```

### 3.3 禁止拷贝

```cpp
// 方法1: 将拷贝操作设为delete
class NonCopyable {
public:
    NonCopyable() = default;
    NonCopyable(const NonCopyable&) = delete;
    NonCopyable& operator=(const NonCopyable&) = delete;
};

// 方法2: 继承NonCopyable基类
class NonCopyableBase {
protected:
    NonCopyableBase() = default;
    ~NonCopyableBase() = default;
    
    NonCopyableBase(const NonCopyableBase&) = delete;
    NonCopyableBase& operator=(const NonCopyableBase&) = delete;
};

class MyClass : private NonCopyableBase {
    // MyClass自动禁止拷贝
};
```

## 四、移动语义

### 4.1 移动构造函数

```cpp
class MyClass {
public:
    // 移动构造函数
    MyClass(MyClass&& other) noexcept
        : data_(other.data_)
        , size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
        std::cout << "Move constructor" << std::endl;
    }
    
    // C++11: 显式请求默认移动构造函数
    MyClass(MyClass&&) noexcept = default;
    
    // C++11: 禁止移动
    MyClass(MyClass&&) = delete;
    
private:
    int* data_;
    size_t size_;
};

// 调用时机
MyClass obj1;
MyClass obj2 = std::move(obj1);  // 移动构造
MyClass obj3(std::move(obj1));   // 移动构造
MyClass obj4 = create_object();  // 移动构造（可能被优化）
```

### 4.2 移动赋值运算符

```cpp
class MyClass {
public:
    // 移动赋值运算符
    MyClass& operator=(MyClass&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
        }
        std::cout << "Move assignment" << std::endl;
        return *this;
    }
    
    // 使用move-and-swap惯用法
    MyClass& operator=(MyClass other) noexcept {  // 按值传递
        swap(*this, other);
        return *this;
    }
    
    friend void swap(MyClass& a, MyClass& b) noexcept {
        std::swap(a.data_, b.data_);
        std::swap(a.size_, b.size_);
    }
    
private:
    int* data_;
    size_t size_;
};

// 调用时机
MyClass obj1, obj2;
obj2 = std::move(obj1);  // 移动赋值
obj1 = std::move(obj1);  // 自赋值
```

### 4.3 noexcept的重要性

```cpp
class MyClass {
public:
    // 正确：移动操作应该是noexcept
    MyClass(MyClass&& other) noexcept 
        : data_(other.data_)
        , size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }
    
    // 错误：移动操作不应该抛出异常
    // MyClass(MyClass&& other) { /* ... */ }
};

// 原因：STL容器在重新分配时优先使用移动操作
// 如果移动操作可能抛出异常，STL会回退到拷贝操作
std::vector<MyClass> vec;
vec.push_back(MyClass());  // 容器扩容时使用移动构造
```

## 五、析构函数

### 5.1 基本用法

```cpp
class MyClass {
public:
    MyClass() : data_(new int[100]) {
        std::cout << "Constructor" << std::endl;
    }
    
    ~MyClass() {
        std::cout << "Destructor" << std::endl;
        delete[] data_;
    }
    
private:
    int* data_;
};

// 调用时机
{
    MyClass obj;  // 调用构造函数
}  // 调用析构函数

// 异常安全
MyClass* ptr = new MyClass();
try {
    // 可能抛出异常的代码
} catch (...) {
    delete ptr;  // 仍然调用析构函数
    throw;
}
delete ptr;
```

### 5.2 虚析构函数

```cpp
class Base {
public:
    // 正确：多态基类应该有虚析构函数
    virtual ~Base() {
        std::cout << "Base destructor" << std::endl;
    }
};

class Derived : public Base {
public:
    ~Derived() override {
        std::cout << "Derived destructor" << std::endl;
        delete[] data_;
    }
    
private:
    int* data_ = new int[100];
};

// 使用
Base* ptr = new Derived();
delete ptr;  // 正确调用Derived析构函数

// 如果Base的析构函数不是虚函数
// 只会调用Base析构函数，导致内存泄漏
```

### 5.3 析构函数的异常

```cpp
class MyClass {
public:
    ~MyClass() noexcept {  // C++11: 析构函数默认是noexcept
        try {
            // 清理资源
        } catch (...) {
            // 析构函数不应该抛出异常
            // 如果抛出，会调用std::terminate
        }
    }
};

// C++17: 析构函数隐式是noexcept
class MyClass {
public:
    ~MyClass() {  // 自动是noexcept
        // 析构函数
    }
};
```

## 六、C++11新特性

### 6.1 default和delete

```cpp
class MyClass {
public:
    // = default: 显式请求编译器生成默认版本
    MyClass() = default;
    MyClass(const MyClass&) = default;
    MyClass& operator=(const MyClass&) = default;
    ~MyClass() = default;
    
    // = delete: 显式禁止某个函数
    MyClass(MyClass&&) = delete;
    MyClass& operator=(MyClass&&) = delete;
    
    // 禁止特定类型的拷贝
    MyClass& operator=(const MyClass&) = delete;
    
    // 禁止特定参数类型
    void func(int) = delete;
    void func(double) = delete;
    void func(std::string) = delete;
};

// 使用
MyClass obj1;
MyClass obj2 = obj1;  // OK: 使用默认拷贝构造
// MyClass obj3 = std::move(obj1);  // 错误：移动构造被删除
```

### 6.2 override和final

```cpp
class Base {
public:
    virtual void func1() {
        std::cout << "Base func1" << std::endl;
    }
    
    virtual void func2() {
        std::cout << "Base func2" << std::endl;
    }
};

class Derived : public Base {
public:
    // override: 确保覆盖基类虚函数
    void func1() override {
        std::cout << "Derived func1" << std::endl;
    }
    
    // 错误：没有对应的基类虚函数
    // void func3() override {}
    
    // final: 禁止进一步覆盖
    void func2() final {
        std::cout << "Derived func2 (final)" << std::endl;
    }
};

class FurtherDerived : public Derived {
public:
    // OK: func1可以覆盖
    void func1() override {
        std::cout << "FurtherDerived func1" << std::endl;
    }
    
    // 错误：func2是final，不能覆盖
    // void func2() override {}
};

// final也可以用于类
class FinalClass final {
    // 不能被继承
};

// 错误：FinalClass是final
// class DerivedFromFinal : public FinalClass {};
```

### 6.3 noexcept

```cpp
class MyClass {
public:
    // noexcept: 函数不会抛出异常
    void safe_function() noexcept {
        // 不会抛出异常
    }
    
    // 条件noexcept
    void conditional_noexcept() noexcept(noexcept(some_function())) {
        some_function();
    }
    
    // 移动操作应该是noexcept
    MyClass(MyClass&& other) noexcept 
        : data_(other.data_) {
        other.data_ = nullptr;
    }
    
private:
    int* data_;
};

// 优势
// 1. 帮助编译器优化
// 2. 允许STL使用移动操作
// 3. 提供更好的异常安全保证
```

## 八、面试常见问题

### Q1: 什么是五法则？

**答案：**
五法则是指在C++11中，如果定义了以下任何一个函数，应该定义所有五个：

1. 析构函数
2. 拷贝构造函数
3. 拷贝赋值运算符
4. 移动构造函数
5. 移动赋值运算符

### Q2: 什么是委托构造函数？

**答案：**
委托构造函数是指一个构造函数调用同一个类的另一个构造函数来完成初始化。

```cpp
class MyClass {
public:
    MyClass(int x, int y, int z) : x_(x), y_(y), z_(z) {}
    MyClass(int x) : MyClass(x, 0, 0) {}  // 委托构造
};
```

### Q3: 什么时候应该将析构函数声明为虚函数？

**答案：**
当类被用作多态基类时，析构函数应该声明为虚函数，以确保通过基类指针删除派生类对象时，会调用正确的析构函数。

### Q4: 什么是copy-and-swap惯用法？

**答案：**
copy-and-swap是一种异常安全的拷贝赋值实现方式，通过创建临时对象、交换资源、自动销毁临时对象来实现。

```cpp
MyClass& operator=(MyClass other) {
    swap(*this, other);
    return *this;
}
```

### Q5: 为什么移动操作应该是noexcept？

**答案：**
1. STL容器在重新分配时优先使用移动操作
2. 如果移动操作可能抛出异常，STL会回退到拷贝操作
3. noexcept提供更好的性能和异常安全保证

### Q6: override和final的作用是什么？

**答案：**
- **override**：确保函数覆盖基类虚函数，编译器会检查
- **final**：禁止函数被进一步覆盖，或禁止类被继承

### Q7: default和delete的作用是什么？

**答案：**
- **= default**：显式请求编译器生成默认版本
- **= delete**：显式禁止某个函数

### Q8: 什么是继承构造函数？

**答案：**
继承构造函数允许派生类继承基类的所有构造函数，避免重复代码。

```cpp
class Derived : public Base {
public:
    using Base::Base;
};
```

### Q9: 类内成员初始化器有什么优势？

**答案：**
1. 减少构造函数重复代码
2. 清晰表达默认值
3. 支持非静态成员的默认值

### Q10: 什么是初始化列表构造函数？

**答案：**
初始化列表构造函数接受`std::initializer_list`参数，允许使用列表初始化语法创建对象。

```cpp
Vector v = {1, 2, 3, 4, 5};
```

## 九、最佳实践

### 9.1 遵循五法则

```cpp
class MyClass {
public:
    ~MyClass();                    // 析构函数
    MyClass(const MyClass&);       // 拷贝构造

    MyClass& operator=(MyClass&&) noexcept;  // 移动赋值

### 9.3 移动操作标记为noexcept

class MyClass {

### 9.4 多态基类使用虚析构函数

};
```

## 十、总结

类的特殊成员函数是C++面向对象编程的核心：

**核心概念：**
1. 五法则
2. 委托构造
3. 继承构造
4. 移动语义
5. RAII

**C++11新特性：**
1. default/delete
2. override/final
3. noexcept
4. 类内成员初始化器

**最佳实践：**
1. 遵循五法则
2. 使用override和final
3. 移动操作标记为noexcept
4. 多态基类使用虚析构函数
5. 使用RAII管理资源

掌握类的特殊成员函数是C++开发的基本功，也是面试中的必考点。
