# 别名与类型推导 (C++11-20)

## 一、using别名声明

### 1.1 基本用法

```cpp
// C++11: using别名声明
using MyInt = int;
using String = std::string;
using IntVector = std::vector<int>;

// 对比typedef
typedef int MyInt;
typedef std::string String;
typedef std::vector<int> IntVector;
```

### 1.2 别名模板

```cpp
// C++11: 别名模板
template<typename T>
using Vector = std::vector<T>;

template<typename K, typename V>
using Map = std::map<K, V>;

// 使用
Vector<int> vec;
Map<std::string, int> m;

// typedef不能做到
// template<typename T>
// typedef std::vector<T> Vector<T>;  // 错误
```

### 1.3 函数指针别名

```cpp
// using更简洁
using FuncPtr = void(*)(int);
using MemberFuncPtr = void (MyClass::*)(int);

// typedef版本
typedef void (*FuncPtr)(int);
typedef void (MyClass::*MemberFuncPtr)(int);
```

## 二、auto类型推导

### 2.1 基本推导

```cpp
// auto推导
auto x = 42;                    // int
auto y = 3.14;                  // double
auto z = "hello";               // const char*
auto s = std::string("world");  // std::string
auto vec = std::vector<int>();  // std::vector<int>

// 引用
auto& ref = x;  // int&
const auto& cref = x;  // const int&
```

### 2.2 auto推导规则

```cpp
// auto会丢弃引用和const
int x = 42;
const int& cref = x;

auto a = cref;      // int（丢弃const和引用）
auto& b = cref;     // const int&（保留const）
const auto& c = cref;  // const int&（显式const）

// auto初始化列表
auto list = {1, 2, 3};  // std::initializer_list<int>
// auto x2 = {1};        // 错误：有歧义
```

### 2.3 函数返回类型推导

```cpp
// C++14: 自动推导返回类型
auto add(int a, int b) {
    return a + b;  // int
}

auto get_string() {
    return "Hello";  // const char*
}

// 尾返回类型
template<typename T, typename U>
auto add(T a, U b) -> decltype(a + b) {
    return a + b;
}
```

### 2.4 泛型lambda

```cpp
// C++14: 泛型lambda
auto lambda = [](auto x, auto y) {
    return x + y;
};

lambda(1, 2);        // int
lambda(1.5, 2.5);    // double
```

## 三、decltype

### 3.1 基本用法

```cpp
// decltype推导表达式的确切类型
int x = 42;
decltype(x) y = 100;  // int

// 推导函数返回类型
int func();
decltype(func()) z = func();  // int

// 推导复杂表达式
std::vector<int> vec;
decltype(vec.begin()) it = vec.begin();  // std::vector<int>::iterator
```

### 3.2 decltype规则

```cpp
// decltype保留引用和const
int x = 42;
const int& cref = x;

decltype(cref) a = x;  // const int&

// decltype(auto)（C++14）
template<typename T>
auto get_value(T& container) -> decltype(auto) {
    return container[0];  // 保持引用类型
}
```

### 3.3 decltype(auto)

```cpp
// decltype(auto)保留表达式的确切类型
auto x = 42;
const auto& cx = x;

decltype(auto) y = x;   // int
decltype(auto) z = cx;  // const int&

// 函数返回
decltype(auto) get_first(std::vector<int>& v) {
    return v[0];  // int&
}
```

## 四、decltype(auto) vs auto

```cpp
// auto丢弃引用
auto get_value(std::vector<int>& v) {
    return v[0];  // int
}

// decltype(auto)保留引用
decltype(auto) get_value_ref(std::vector<int>& v) {
    return v[0];  // int&
}

// 使用
std::vector<int> v = {1, 2, 3};
auto val = get_value(v);
val = 100;  // 不影响v[0]

auto& ref = get_value_ref(v);
ref = 100;  // 修改v[0]
```

## 五、面试常见问题

### Q1: using和typedef有什么区别？

**答案：**
- using更简洁，支持别名模板
- typedef语法复杂，不支持别名模板

### Q2: auto和decltype有什么区别？

**答案：**
- auto推导类型时丢弃引用和const
- decltype推导表达式的确切类型，保留引用和const

### Q3: decltype(auto)有什么用途？

**答案：**
decltype(auto)用于需要保留表达式确切类型的场景，特别是返回引用时。

### Q4: 别名模板有什么优势？

**答案：**
别名模板可以简化复杂类型的定义，提高代码可读性。

## 六、最佳实践

### 6.1 优先使用using

```cpp
// 好的实践
using MyVector = std::vector<int>;

// 避免
typedef std::vector<int> MyVector;
```

### 6.2 合理使用auto

```cpp
// 好的实践
auto it = vec.begin();
auto result = std::find(vec.begin(), vec.end(), 42);

// 避免过度使用
// auto x = calculate();  // 类型不明确
```

### 6.3 使用decltype(auto)返回引用

```cpp
decltype(auto) get_first(std::vector<int>& v) {
    return v[0];  // 返回引用
}
```
