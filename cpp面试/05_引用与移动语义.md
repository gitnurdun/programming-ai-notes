# 引用与移动语义详解 (C++11-20)

## 一、引用基础

### 1.1 左值引用（Lvalue Reference）

左值引用是C++98引入的特性，用于绑定到左值。

```cpp
// 左值引用语法
int x = 10;
int& ref = x;  // 左值引用

// 左值引用必须绑定到左值
int& ref2 = 10;  // 错误：10是右值
const int& cref = 10;  // 正确：const左值引用可以绑定到右值

// 左值引用作为参数
void func(int& x) {
    x = 20;
}

int main() {
    int a = 10;
    func(a);  // OK
    func(10); // 错误：不能绑定右值
}
```

### 1.2 右值引用（Rvalue Reference）- C++11

右值引用是C++11引入的特性，专门用于绑定到右值（临时对象）。

```cpp
// 右值引用语法
int&& rref = 10;  // 绑定到临时对象
int&& rref2 = std::move(x);  // 将左值转换为右值引用

// 右值引用的特性
std::cout << rref;  // 10

// 修改右值引用
rref = 20;
std::cout << x;  // 20（x也被修改了，因为rref绑定到了x的右值引用）

// 右值引用可以延长临时对象的生命周期
std::string&& str_ref = get_string();  // 临时对象生命周期延长
std::cout << str_ref;  // 安全使用
```

### 1.3 左值与右值

```cpp
// 左值（有名字、可以取地址）
int x = 10;           // x是左值
int& ref = x;         // ref是左值
*ptr                  // 解引用结果是左值
x + 1                 // 表达式结果是右值
x = 20;               // x是左值
func()                // 返回非引用类型是右值

// 右值（临时对象、字面量）
10                    // 字面量
x + 1                 // 算术表达式结果
std::string("hello")  // 临时对象
func()                // 返回值类型
```

## 二、移动语义（Move Semantics）

### 2.1 移动语义的概念

移动语义允许将资源（如堆内存、文件句柄）从一个对象"移动"到另一个对象，而不是拷贝。

**传统拷贝的问题：**
```cpp
class String {
public:
    String(const char* str = "") {
        data_ = new char[strlen(str) + 1];
        strcpy(data_, str);
    }
    
    // 拷贝构造函数 - 深拷贝
    String(const String& other) {
        data_ = new char[strlen(other.data_) + 1];
        strcpy(data_, other.data_);
    }
    
    ~String() {
        delete[] data_;
    }
    
private:
    char* data_;
};

// 问题：不必要的拷贝
String str1 = "Hello";
String str2 = str1;  // 深拷贝，分配新内存
```

**移动语义的解决方案：**
```cpp
class String {
public:
    String(const char* str = "") {
        data_ = new char[strlen(str) + 1];
        strcpy(data_, str);
    }
    
    // 移动构造函数 - 窃取资源
    String(String&& other) noexcept {
        data_ = other.data_;  // 直接接管指针
        other.data_ = nullptr;  // 将原对象置空
    }
    
    ~String() {
        delete[] data_;
    }
    
private:
    char* data_;
};

// 移动语义避免不必要的拷贝
String str1 = "Hello";
String str2 = std::move(str1);  // 移动，不分配新内存
// str1现在为空，str2拥有原来的资源
```

### 2.2 移动构造函数

```cpp
class MyClass {
public:
    MyClass() {
        data_ = new int[1000];
        std::cout << "Default constructor" << std::endl;
    }
    
    // 移动构造函数
    MyClass(MyClass&& other) noexcept {
        data_ = other.data_;      // 接管资源
        size_ = other.size_;
        other.data_ = nullptr;    // 清空原对象
        other.size_ = 0;
        std::cout << "Move constructor" << std::endl;
    }
    
    ~MyClass() {
        delete[] data_;
    }
    
private:
    int* data_;
    size_t size_;
};

// 使用
MyClass obj1;
MyClass obj2 = std::move(obj1);  // 调用移动构造函数
```

### 2.3 移动赋值运算符

```cpp
class MyClass {
public:
    // 移动赋值运算符
    MyClass& operator=(MyClass&& other) noexcept {
        if (this != &other) {
            delete[] data_;        // 释放当前资源
            data_ = other.data_;   // 接管新资源
            size_ = other.size_;
            other.data_ = nullptr; // 清空原对象
            other.size_ = 0;
        }
        return *this;
    }
    
private:
    int* data_;
    size_t size_;
};

// 使用
MyClass obj1, obj2;
obj2 = std::move(obj1);  // 调用移动赋值运算符
```

### 2.4 noexcept的重要性

移动操作应该标记为`noexcept`，因为：
1. STL容器在重新分配时优先使用移动操作
2. 如果移动操作可能抛出异常，STL会回退到拷贝操作

```cpp
class MyClass {
public:
    // 正确：移动操作应该是noexcept
    MyClass(MyClass&& other) noexcept { /* ... */ }
    MyClass& operator=(MyClass&& other) noexcept { /* ... */ }
    
    // 错误：移动操作不应该抛出异常
    // MyClass(MyClass&& other) { /* ... */ }
};
```

## 三、std::move

### 3.1 std::move的作用

`std::move`将左值转换为右值引用，启用移动语义。

```cpp
#include <utility>

std::string str1 = "Hello";
std::string str2 = str1;      // 拷贝
std::string str3 = std::move(str1);  // 移动

// std::move的实现原理
template<typename T>
typename std::remove_reference<T>::type&& move(T&& arg) noexcept {
    return static_cast<typename std::remove_reference<T>::type&&>(arg);
}
```

### 3.2 std::move使用场景

```cpp
// 1. 容器元素移动
std::vector<std::string> vec;
vec.push_back(std::string("Hello"));  // 临时对象自动移动
std::string str = "World";
vec.push_back(std::move(str));        // 显式移动

// 2. 函数返回值优化
std::string create_string() {
    std::string result = "Hello";
    return result;  // 自动移动（RVO/NRVO）
}

// 3. 容器重分配
std::vector<MyClass> vec;
vec.push_back(MyClass());
vec.push_back(MyClass());  // 容器扩容时移动元素

// 4. 交换函数
template<typename T>
void swap(T& a, T& b) noexcept {
    T temp = std::move(a);
    a = std::move(b);
    b = std::move(temp);
}
```

### 3.3 std::move的陷阱

```cpp
// 陷阱1：移动后不要使用原对象
std::string str = "Hello";
std::string str2 = std::move(str);
// std::cout << str;  // 危险：str可能处于未定义状态

// 陷阱2：const对象不能移动
const std::string cstr = "Hello";
// std::string str2 = std::move(cstr);  // 错误：调用拷贝构造函数

// 陷阱3：std::move不移动任何东西
std::string str = "Hello";
std::move(str);  // 什么也没发生
std::string str2 = std::move(str);  // 这里才真正移动
```

## 四、完美转发（Perfect Forwarding）

### 4.1 完美转发的概念

完美转发是指在函数模板中，将参数精确地转发给另一个函数，保持参数的值类别（左值/右值）和const/volatile属性。

### 4.2 万能引用（Universal Reference）

```cpp
// 万能引用语法
template<typename T>
void func(T&& arg);  // T&& 是万能引用

// 万能引用的条件：
// 1. 必须是模板参数
// 2. 必须是T&&形式
// 3. T必须被推导

// 不是万能引用的情况
class MyClass {
    template<typename T>
    void func(T&& arg);  // 是万能引用
    
    template<typename T>
    void func(const T&& arg);  // 不是：有const
    
    void func(std::string&& arg);  // 不是：类型已确定
};
```

### 4.3 引用折叠规则

万能引用的推导涉及引用折叠：

```cpp
// 引用折叠规则
T& + &   -> T&      // 左值引用 + 左值引用 = 左值引用
T& + &&  -> T&      // 左值引用 + 右值引用 = 左值引用
T&& + &   -> T&      // 右值引用 + 左值引用 = 左值引用
T&& + &&  -> T&&     // 右值引用 + 右值引用 = 右值引用

// 示例
template<typename T>
void func(T&& arg);

int x = 10;
func(x);    // T推导为int&，参数类型为int&（左值引用）
func(10);   // T推导为int，参数类型为int&&（右值引用）
```

### 4.4 std::forward

```cpp
#include <utility>

// std::forward的实现
template<typename T>
T&& forward(typename std::remove_reference<T>::type& arg) noexcept {
    return static_cast<T&&>(arg);
}

template<typename T>
T&& forward(typename std::remove_reference<T>::type&& arg) noexcept {
    static_assert(!std::is_lvalue_reference<T>::value, "Cannot forward an rvalue as an lvalue");
    return static_cast<T&&>(arg);
}

// 完美转发示例
template<typename T>
void wrapper(T&& arg) {
    target(std::forward<T>(arg));  // 完美转发
}

void target(std::string& arg) {
    std::cout << "Lvalue reference" << std::endl;
}

void target(std::string&& arg) {
    std::cout << "Rvalue reference" << std::endl;
}

// 使用
std::string str = "Hello";
wrapper(str);      // 输出：Lvalue reference
wrapper(std::string("World"));  // 输出：Rvalue reference
```

### 4.5 完美转发的应用

```cpp
// 1. 工厂函数
template<typename T, typename... Args>
std::unique_ptr<T> make_unique(Args&&... args) {
    return std::unique_ptr<T>(new T(std::forward<Args>(args)...));
}

// 2. 容器构造
template<typename T, typename... Args>
std::vector<T> make_vector(Args&&... args) {
    std::vector<T> vec;
    (vec.push_back(std::forward<Args>(args)), ...);  // C++17折叠表达式
    return vec;
}

// 3. 线程参数传递
template<typename F, typename... Args>
auto create_thread(F&& f, Args&&... args) {
    return std::thread(std::forward<F>(f), std::forward<Args>(args)...);
}

// 4. 回调注册
template<typename Callback, typename... Args>
void register_callback(Callback&& cb, Args&&... args) {
    callbacks_.push_back([cb = std::forward<Callback>(cb), args...]() {
        cb(args...);
    });
}
```

## 五、值类别详解

### 5.1 值类别分类（C++17）

C++17将表达式分为三大类：

```
表达式
├── glvalue（泛左值）
│   ├── lvalue（左值）
│   └── xvalue（将亡值）
└── rvalue（泛右值）
    ├── prvalue（纯右值）
    └── xvalue（将亡值）
```

### 5.2 各类别的定义

```cpp
// lvalue（左值）：有名字、可以取地址
int x = 10;           // x是lvalue
int& ref = x;         // ref是lvalue
*ptr                  // 解引用结果是lvalue
x = 20;               // 赋值左操作数是lvalue

// prvalue（纯右值）：临时对象、字面量
10                    // 字面量
x + 1                 // 算术表达式
std::string("hello")  // 临时对象
func()                // 返回非引用类型

// xvalue（将亡值）：可以被移动的资源
std::move(x)          // std::move的结果
std::vector<int>().begin()[0]  // 容器元素的右值引用

// glvalue（泛左值）：lvalue + xvalue
// rvalue（泛右值）：prvalue + xvalue
```

### 5.3 值类别判断

```cpp
// 辅助函数判断值类别
template<typename T>
struct value_category {
    static constexpr const char* value = "prvalue";
};

template<typename T>
struct value_category<T&> {
    static constexpr const char* value = "lvalue";
};

template<typename T>
struct value_category<T&&> {
    static constexpr const char* value = "xvalue";
};

// 使用
int x = 10;
std::cout << value_category<decltype(x)>::value;      // lvalue
std::cout << value_category<decltype(10)>::value;     // prvalue
std::cout << value_category<decltype(std::move(x))>::value;  // xvalue
```

## 六、移动语义的实际应用

### 6.1 实现可移动类

```cpp
class Resource {
public:
    Resource() {
        data_ = new int[1000];
        std::cout << "Resource created" << std::endl;
    }
    
    // 拷贝构造
    Resource(const Resource& other) {
        data_ = new int[1000];
        std::copy(other.data_, other.data_ + 1000, data_);
        std::cout << "Resource copied" << std::endl;
    }
    
    // 移动构造
    Resource(Resource&& other) noexcept {
        data_ = other.data_;
        other.data_ = nullptr;
        std::cout << "Resource moved" << std::endl;
    }
    
    // 拷贝赋值
    Resource& operator=(const Resource& other) {
        if (this != &other) {
            delete[] data_;
            data_ = new int[1000];
            std::copy(other.data_, other.data_ + 1000, data_);
        }
        return *this;
    }
    
    // 移动赋值
    Resource& operator=(Resource&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            other.data_ = nullptr;
        }
        return *this;
    }
    
    ~Resource() {
        delete[] data_;
        std::cout << "Resource destroyed" << std::endl;
    }
    
private:
    int* data_;
};

// 使用
std::vector<Resource> resources;
resources.push_back(Resource());      // 移动
resources.push_back(Resource());      // 移动
```

### 6.2 智能指针与移动语义

```cpp
// unique_ptr的移动
std::unique_ptr<int> ptr1 = std::make_unique<int>(42);
std::unique_ptr<int> ptr2 = std::move(ptr1);  // 移动
// ptr1现在为nullptr，ptr2拥有资源

// 在函数中返回unique_ptr
std::unique_ptr<int> create_ptr() {
    return std::make_unique<int>(42);  // 自动移动
}

// 完美转发unique_ptr
template<typename T, typename... Args>
std::unique_ptr<T> make_unique_custom(Args&&... args) {
    return std::unique_ptr<T>(new T(std::forward<Args>(args)...));
}
```

### 6.3 容器与移动语义

```cpp
// vector的移动
std::vector<std::string> vec1 = {"Hello", "World"};
std::vector<std::string> vec2 = std::move(vec1);  // O(1)移动
// vec1现在为空

// 插入元素
std::vector<std::string> vec;
std::string str = "Hello";
vec.push_back(std::move(str));  // 移动插入

// 容器重分配
std::vector<std::string> vec2;
for (int i = 0; i < 100; ++i) {
    vec2.push_back(std::string("Item " + std::to_string(i)));
    // 容器扩容时，元素会被移动而不是拷贝
}
```

### 6.4 PImpl模式与移动语义

```cpp
// PImpl (Pointer to Implementation) 模式
class MyClass {
public:
    MyClass() : impl_(new Impl()) {}
    
    // 移动构造
    MyClass(MyClass&& other) noexcept : impl_(other.impl_) {
        other.impl_ = nullptr;
    }
    
    // 移动赋值
    MyClass& operator=(MyClass&& other) noexcept {
        if (this != &other) {
            delete impl_;
            impl_ = other.impl_;
            other.impl_ = nullptr;
        }
        return *this;
    }
    
    ~MyClass() {
        delete impl_;
    }
    
    void do_something() {
        impl_->do_something();
    }
    
private:
    struct Impl {
        void do_something() {
            std::cout << "Doing something" << std::endl;
        }
    };
    
    Impl* impl_;
};
```

## 七、移动语义的性能优化

### 7.1 RVO/NRVO

```cpp
// RVO (Return Value Optimization)
std::string create_string() {
    return "Hello";  // 编译器优化，直接在调用者处构造
}

// NRVO (Named Return Value Optimization)
std::string create_string() {
    std::string result = "Hello";
    return result;  // 编译器优化，result直接构造在调用者处
}

// 即使没有std::move，编译器也会优化
std::string func() {
    std::string str = "Hello";
    return str;  // 移动或优化
}
```

### 7.2 移动语义避免的拷贝

```cpp
// 没有移动语义（C++98）
std::vector<std::string> create_vector() {
    std::vector<std::string> result;
    result.push_back("Hello");
    result.push_back("World");
    return result;  // 拷贝整个vector
}

// 有移动语义（C++11+）
std::vector<std::string> create_vector() {
    std::vector<std::string> result;
    result.push_back("Hello");
    result.push_back("World");
    return result;  // 移动vector，不拷贝元素
}
```

### 7.3 性能对比

```cpp
// 拷贝版本
void copy_version() {
    std::vector<std::string> vec;
    for (int i = 0; i < 10000; ++i) {
        std::string str = "Item " + std::to_string(i);
        vec.push_back(str);  // 拷贝
    }
}

// 移动版本
void move_version() {
    std::vector<std::string> vec;
    for (int i = 0; i < 10000; ++i) {
        std::string str = "Item " + std::to_string(i);
        vec.push_back(std::move(str));  // 移动
    }
}

// 移动版本通常快得多
```

## 八、移动语义的陷阱

### 8.1 自移动

```cpp
// 自移动
std::string str = "Hello";
str = std::move(str);  // 自移动，结果是未定义的！

// 正确的移动赋值
class MyClass {
public:
    MyClass& operator=(MyClass&& other) noexcept {
        if (this != &other) {  // 检查自赋值
            delete[] data_;
            data_ = other.data_;
            other.data_ = nullptr;
        }
        return *this;
    }
};
```

### 8.2 移动后使用

```cpp
// 移动后不要使用原对象
std::vector<int> vec = {1, 2, 3, 4, 5};
std::vector<int> vec2 = std::move(vec);
// std::cout << vec.size();  // 危险：vec可能为空

// 正确做法：移动后立即让原对象离开作用域
std::vector<int> create_vector() {
    std::vector<int> vec = {1, 2, 3, 4, 5};
    return std::move(vec);  // 离开作用域，安全
}
```

### 8.3 const对象不能移动

```cpp
// const对象调用拷贝而不是移动
const std::string str = "Hello";
std::string str2 = std::move(str);  // 调用拷贝构造函数

// 原因：const右值引用不能绑定到const对象
// const T&& 不能绑定到 const T&
```

### 8.4 移动不是真的"移动"

```cpp
// 移动只是转移资源所有权
std::string str1 = "Hello";
std::string str2 = std::move(str1);

// str1可能仍然有值，但处于"有效但未指定"状态
// str1.size()可能返回原来的大小
// 但str1的内容是未定义的

// 正确做法：移动后不要再使用原对象
```

## 九、面试常见问题

### Q1: 什么是左值和右值？

**答案：**
- **左值（lvalue）**：有名字、可以取地址的表达式，代表一个持久的对象
- **右值（rvalue）**：临时对象、字面值，代表一个即将销毁的对象

```cpp
int x = 10;        // x是左值，10是右值
x + 1;             // 结果是右值
func();            // 返回值是右值
```

### Q2: 什么是移动语义？它解决了什么问题？

**答案：**
移动语义允许将资源从一个对象"移动"到另一个对象，而不是拷贝。

**解决的问题：**
1. 避免不必要的深拷贝
2. 提高性能，特别是对于包含资源的对象
3. 实现高效的资源转移

```cpp
std::string str1 = "Hello";
std::string str2 = std::move(str1);  // 移动，不分配新内存
```

### Q3: 解释std::move的作用

**答案：**
`std::move`将左值转换为右值引用，启用移动语义。

```cpp
std::string str = "Hello";
std::string str2 = str;        // 拷贝
std::string str3 = std::move(str);  // 移动
```

### Q4: 什么是完美转发？如何实现？

**答案：**
完美转发是指在函数模板中，将参数精确地转发给另一个函数，保持参数的值类别。

**实现：**
```cpp
template<typename T>
void wrapper(T&& arg) {
    target(std::forward<T>(arg));  // 完美转发
}
```

### Q5: 什么是万能引用？

**答案：**
万能引用是可以绑定到左值或右值的引用。

```cpp
template<typename T>
void func(T&& arg);  // T&& 是万能引用

// 使用
int x = 10;
func(x);     // 绑定到左值
func(10);    // 绑定到右值
```

### Q6: 解释引用折叠规则

**答案：**
引用折叠规则：
- T& + & → T&
- T& + && → T&
- T&& + & → T&
- T&& + && → T&&

### Q7: 为什么移动操作应该是noexcept？

**答案：**
1. STL容器在重新分配时优先使用移动操作
2. 如果移动操作可能抛出异常，STL会回退到拷贝操作
3. noexcept保证移动操作不会抛出异常，提高性能

```cpp
MyClass(MyClass&& other) noexcept { /* ... */ }
```

### Q8: 移动语义有什么陷阱？

**答案：**
1. **自移动**：`x = std::move(x)` 导致未定义行为
2. **移动后使用**：移动后不要使用原对象
3. **const对象不能移动**：会调用拷贝而不是移动
4. **移动不是真的"移动"**：只是转移资源所有权

### Q9: 什么是RVO/NRVO？

**答案：**
- **RVO (Return Value Optimization)**：返回值优化，编译器直接在调用者处构造返回值
- **NRVO (Named Return Value Optimization)**：命名返回值优化，编译器优化返回局部变量

```cpp
std::string func() {
    return "Hello";  // RVO
}

std::string func2() {
    std::string result = "Hello";
    return result;  // NRVO
}
```

### Q10: 移动语义和拷贝语义有什么区别？

**答案：**
| 特性 | 拷贝语义 | 移动语义 |
|------|----------|----------|
| 资源处理 | 深拷贝 | 转移所有权 |
| 性能 | 慢（需要分配内存） | 快（只是指针操作） |
| 原对象 | 保持不变 | 进入"有效但未指定"状态 |
| 适用场景 | 需要保留原对象 | 不再需要原对象 |

## 十、最佳实践

### 10.1 优先使用移动语义

```cpp
// 好的实践
std::vector<std::string> vec;
vec.push_back(std::string("Hello"));  // 临时对象自动移动

std::string str = "World";
vec.push_back(std::move(str));        // 显式移动
```

### 10.2 正确实现移动操作

```cpp
class MyClass {
public:
    // 移动构造函数
    MyClass(MyClass&& other) noexcept
        : data_(other.data_)
        , size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }
    
    // 移动赋值运算符
    MyClass& operator=(MyClass&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
        }
        return *this;
    }
};
```

### 10.3 使用完美转发

```cpp
template<typename T>
void wrapper(T&& arg) {
    target(std::forward<T>(arg));  // 完美转发
}
```

### 10.4 标记移动操作为noexcept

```cpp
class MyClass {
public:
    MyClass(MyClass&& other) noexcept { /* ... */ }
    MyClass& operator=(MyClass&& other) noexcept { /* ... */ }
};
```

### 10.5 遵循五法则

如果定义了移动操作，也应该定义拷贝操作和析构函数：

```cpp
class MyClass {
public:
    ~MyClass();                    // 析构函数
    MyClass(const MyClass&);       // 拷贝构造
    MyClass& operator=(const MyClass&);  // 拷贝赋值
    MyClass(MyClass&&) noexcept;   // 移动构造
    MyClass& operator=(MyClass&&) noexcept;  // 移动赋值
};
```

**应用场景：**
1. 容器操作

4. 资源管理
