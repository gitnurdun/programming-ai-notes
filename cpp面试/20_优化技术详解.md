# C++优化技术详解

## 一、编译优化

### 1.1 内联函数

```cpp
// 内联函数建议
inline int add(int a, int b) {
    return a + b;
}

// constexpr函数（自动内联）
constexpr int square(int x) {
    return x * x;
}
```

### 1.2 编译时计算

```cpp
// 编译时计算
constexpr int factorial(int n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}

constexpr int result = factorial(5);  // 编译时计算
```

### 1.3 模板元编程

```cpp
// 模板元编程
template<int N>
struct Factorial {
    static constexpr int value = N * Factorial<N - 1>::value;
};

template<>
struct Factorial<0> {
    static constexpr int value = 1;
};

constexpr int fact5 = Factorial<5>::value;  // 编译时计算
```

## 二、运行时优化

### 2.1 移动语义

```cpp
// 移动语义避免拷贝
std::vector<int> create_vector() {
    std::vector<int> result;
    result.push_back(1);
    result.push_back(2);
    return result;  // 移动，不拷贝
}

// 使用std::move
std::string str = "Hello";
std::string str2 = std::move(str);  // 移动
```

### 2.2 避免不必要的拷贝

```cpp
// 使用const引用避免拷贝
void print_string(const std::string& str) {
    std::cout << str << std::endl;
}

// 使用移动语义
std::string create_string() {
    return "Hello";  // RVO优化
}
```

### 2.3 预分配内存

```cpp
// 预分配容器大小
std::vector<int> vec;
vec.reserve(1000);  // 预分配空间

// 避免频繁重新分配
for (int i = 0; i < 1000; ++i) {
    vec.push_back(i);
}
```

## 三、内存优化

### 3.1 对象池

```cpp
// 对象池模式
template<typename T>
class ObjectPool {
public:
    T* acquire() {
        if (pool_.empty()) {
            return new T();
        }
        auto obj = pool_.back();
        pool_.pop_back();
        return obj;
    }
    
    void release(T* obj) {
        pool_.push_back(obj);
    }
    
private:
    std::vector<T*> pool_;
};
```

### 3.2 小对象优化

```cpp
// 小对象优化（SSO）
class SmallString {
public:
    SmallString(const char* str) {
        size_t len = strlen(str);
        if (len <= sizeof(buffer_)) {
            memcpy(buffer_, str, len + 1);
            size_ = len;
            is_small_ = true;
        } else {
            ptr_ = new char[len + 1];
            strcpy(ptr_, str);
            size_ = len;
            is_small_ = false;
        }
    }
    
    ~SmallString() {
        if (!is_small_) {
            delete[] ptr_;
        }
    }
    
private:
    union {
        char buffer_[16];
        char* ptr_;
    };
    size_t size_;
    bool is_small_;
};
```

### 3.3 内存池

```cpp
// 内存池
class MemoryPool {
public:
    MemoryPool(size_t block_size, size_t block_count)
        : block_size_(block_size)
        , block_count_(block_count) {
        pool_ = ::operator new(block_size * block_count);
        free_list_.resize(block_count);
        for (size_t i = 0; i < block_count; ++i) {
            free_list_[i] = reinterpret_cast<char*>(pool_) + i * block_size;
        }
    }
    
    ~MemoryPool() {
        ::operator delete(pool_);
    }
    
    void* allocate() {
        if (free_list_.empty()) {
            throw std::bad_alloc();
        }
        void* ptr = free_list_.back();
        free_list_.pop_back();
        return ptr;
    }
    
    void deallocate(void* ptr) {
        free_list_.push_back(static_cast<char*>(ptr));
    }
    
private:
    void* pool_;
    size_t block_size_;
    size_t block_count_;
    std::vector<void*> free_list_;
};
```

## 四、算法优化

### 4.1 选择合适的容器

```cpp
// 根据访问模式选择容器
std::vector<int> vec;      // 随机访问
std::list<int> lst;        // 频繁插入删除
std::map<int, int> mp;     // 键值对
std::unordered_map<int, int> ump;  // 哈希表
```

### 4.2 使用高效的算法

```cpp
// 使用std::sort而不是std::list::sort
std::vector<int> vec = {3, 1, 4, 1, 5};
std::sort(vec.begin(), vec.end());

// 使用移动语义
std::vector<std::string> vec;
vec.push_back(std::string("Hello"));  // 移动插入
```

### 4.3 避免不必要的拷贝

```cpp
// 使用string_view避免拷贝
void print_string(std::string_view sv) {
    std::cout << sv << std::endl;
}

std::string str = "Hello";
print_string(str);  // 不拷贝
```

## 五、并发优化

### 5.1 并行算法

```cpp
#include <execution>

// 使用并行算法
std::vector<int> vec(1000000);
std::sort(std::execution::par, vec.begin(), vec.end());

std::for_each(std::execution::par, vec.begin(), vec.end(), [](int& x) {
    x *= 2;
});
```

### 5.2 无锁数据结构

```cpp
// 无锁队列（简化版）
template<typename T>
class LockFreeQueue {
public:
    void push(T value) {
        Node* new_node = new Node(std::move(value));
        Node* old_tail = tail_.load(std::memory_order_relaxed);
        old_tail->next.store(new_node, std::memory_order_release);
        tail_.store(new_node, std::memory_order_release);
    }
    
    bool pop(T& value) {
        Node* old_head = head_.load(std::memory_order_acquire);
        Node* new_head = old_head->next.load(std::memory_order_acquire);
        if (new_head == nullptr) {
            return false;
        }
        value = std::move(new_head->data);
        head_.store(new_head, std::memory_order_release);
        delete old_head;
        return true;
    }
    
private:
    struct Node {
        T data;
        std::atomic<Node*> next{nullptr};
        
        Node(T&& d) : data(std::move(d)) {}
    };
    
    std::atomic<Node*> head_;
    std::atomic<Node*> tail_;
};
```

## 六、面试常见问题

### Q1: 如何优化C++代码性能？

**答案：**
1. 使用编译时计算
2. 利用移动语义
3. 预分配内存
4. 选择合适的容器和算法
5. 使用并行算法

### Q2: 什么是小对象优化？

**答案：**
小对象优化（SSO）是指对于小对象，直接存储在对象内部，避免堆分配。

### Q3: 什么是对象池？

**答案：**
对象池是一种重用对象的技术，避免频繁的创建和销毁。

### Q4: 如何避免内存碎片？

**答案：**
1. 使用内存池
2. 预分配大块内存
3. 使用固定大小的分配器
