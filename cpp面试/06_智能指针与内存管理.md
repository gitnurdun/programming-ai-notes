# 智能指针与内存管理 (C++11-20)

## 一、智能指针概述

### 1.1 为什么需要智能指针

C++98时代的内存管理问题：
```cpp
// 传统指针的问题
void traditional_pointer() {
    int* ptr = new int(42);
    
    // 问题1：忘记delete
    if (some_condition) {
        return;  // 内存泄漏！
    }
    
    // 问题2：异常导致内存泄漏
    throw std::runtime_error("Error");
    
    delete ptr;  // 可能永远执行不到
}

// 智能指针的解决方案
void smart_pointer() {
    auto ptr = std::make_unique<int>(42);
    
    // 自动释放，即使发生异常
    if (some_condition) {
        return;  // 自动释放
    }
    
    throw std::runtime_error("Error");  // 自动释放
}
```

### 1.2 智能指针的类型

C++11引入了三种智能指针：

| 类型 | 所有权 | 特点 | 适用场景 |
|------|--------|------|----------|
| unique_ptr | 独占 | 不可拷贝，只能移动 | 单一所有权 |
| shared_ptr | 共享 | 引用计数，可拷贝 | 多个所有者 |
| weak_ptr | 观察 | 不影响引用计数 | 避免循环引用 |

## 二、unique_ptr

### 2.1 基本用法

```cpp
#include <memory>

// 创建unique_ptr
auto ptr1 = std::make_unique<int>(42);
std::unique_ptr<int> ptr2(new int(42));  // 不推荐

// 访问对象
std::cout << *ptr1;  // 42
std::cout << ptr1.get();  // 获取原始指针

// 移动语义
std::unique_ptr<int> ptr3 = std::move(ptr1);  // ptr1变为nullptr
// ptr1现在无效，ptr3拥有资源

// reset操作
ptr3.reset();  // 释放资源，ptr3变为nullptr
ptr3.reset(new int(100));  // 重新分配

// release操作
int* raw_ptr = ptr3.release();  // 释放所有权，返回原始指针
delete raw_ptr;  // 手动删除
```

### 2.2 自定义删除器

```cpp
// 使用函数指针作为删除器
void custom_deleter(int* ptr) {
    std::cout << "Custom deleter called" << std::endl;
    delete ptr;
}

std::unique_ptr<int, void(*)(int*)> ptr1(new int(42), custom_deleter);

// 使用lambda作为删除器
auto deleter = [](int* ptr) {
    std::cout << "Lambda deleter called" << std::endl;
    delete ptr;
};

std::unique_ptr<int, decltype(deleter)> ptr2(new int(42), deleter);

// 使用函数对象
struct FileDeleter {
    void operator()(FILE* file) const {
        if (file) {
            std::cout << "Closing file" << std::endl;
            fclose(file);
        }
    }
};

std::unique_ptr<FILE, FileDeleter> file_ptr(fopen("test.txt", "w"));
```

### 2.3 unique_ptr与数组

```cpp
// 管理数组
std::unique_ptr<int[]> arr(new int[10]);

// 访问数组元素
arr[0] = 1;
arr[1] = 2;

// make_unique创建数组（C++14）
auto arr2 = std::make_unique<int[]>(10);

// 注意：不能使用*ptr访问第一个元素
// 必须使用ptr[index]或ptr.get()
```

### 2.4 make_unique的优势 (C++14)

```cpp
// 优先使用make_unique
auto ptr = std::make_unique<MyClass>(arg1, arg2);

// 优势：
// 1. 更简洁，不需要重复类型
// 2. 异常安全：避免内存泄漏
// 3. 性能更好：一次内存分配

// 不推荐的方式（可能异常不安全）
std::unique_ptr<MyClass> ptr(new MyClass(arg1, arg2));

// 如果new成功，但MyClass构造函数抛出异常，会内存泄漏
```

### 2.5 unique_ptr在类中的应用

```cpp
class MyClass {
public:
    MyClass() : data_(std::make_unique<int[]>(100)) {
        std::cout << "Constructor" << std::endl;
    }
    
    // 独占所有权，不需要拷贝
    MyClass(const MyClass&) = delete;
    MyClass& operator=(const MyClass&) = delete;
    
    // 支持移动
    MyClass(MyClass&&) noexcept = default;
    MyClass& operator=(MyClass&&) noexcept = default;
    
    ~MyClass() {
        std::cout << "Destructor" << std::endl;
        // data_自动释放
    }
    
private:
    std::unique_ptr<int[]> data_;
};
```

## 三、shared_ptr

### 3.1 基本用法

```cpp
#include <memory>

// 创建shared_ptr
auto ptr1 = std::make_shared<int>(42);
std::shared_ptr<int> ptr2(new int(42));  // 不推荐

// 拷贝构造（增加引用计数）
std::shared_ptr<int> ptr3 = ptr1;  // 引用计数 = 2
std::shared_ptr<int> ptr4 = ptr3;  // 引用计数 = 3

// 引用计数
std::cout << ptr1.use_count();  // 3

// 唯一所有权
if (ptr1.unique()) {
    std::cout << "Unique owner" << std::endl;
}

// reset操作
ptr3.reset();  // 引用计数 = 2
ptr1.reset();  // 引用计数 = 1
ptr4.reset();  // 引用计数 = 0，对象被删除
```

### 3.2 shared_ptr的工作原理

```cpp
// shared_ptr内部结构
template<typename T>
class shared_ptr {
private:
    T* ptr_;                    // 指向对象的指针
    ControlBlock* control_;     // 控制块
    
    struct ControlBlock {
        T* ptr;                 // 指向对象的指针
        atomic<int> ref_count;  // 引用计数
        atomic<int> weak_count; // 弱引用计数
        
        void (*deleter)(T*);    // 删除器
    };
};

// 引用计数操作
shared_ptr<int> ptr1 = std::make_shared<int>(42);  // ref_count = 1
shared_ptr<int> ptr2 = ptr1;                       // ref_count = 2
ptr1.reset();                                      // ref_count = 1
ptr2.reset();                                      // ref_count = 0，删除对象
```

### 3.3 自定义删除器

```cpp
// 使用lambda删除器
auto deleter = [](int* ptr) {
    std::cout << "Custom deleter" << std::endl;
    delete ptr;
};

std::shared_ptr<int> ptr(new int(42), deleter);

// 使用函数对象
struct FileDeleter {
    void operator()(FILE* file) const {
        if (file) {
            std::cout << "Closing file" << std::endl;
            fclose(file);
        }
    }
};

std::shared_ptr<FILE> file_ptr(fopen("test.txt", "w"), FileDeleter());
```

### 3.4 shared_ptr与数组

```cpp
// C++17之前：需要自定义删除器
auto array_deleter = [](int* ptr) {
    delete[] ptr;
};

std::shared_ptr<int> arr(new int[10], array_deleter);

// C++17: 支持数组
std::shared_ptr<int[]> arr2(new int[10]);

// 使用make_shared创建数组（C++20）
auto arr3 = std::make_shared<int[]>(10);
```

### 3.5 make_shared的优势

```cpp
// 优先使用make_shared
auto ptr = std::make_shared<MyClass>(arg1, arg2);

// 优势：
// 1. 一次内存分配（对象和控制块在一起）
// 2. 更好的缓存局部性
// 3. 异常安全

// 不推荐的方式
std::shared_ptr<MyClass> ptr(new MyClass(arg1, arg2));

// 问题：
// 1. 两次内存分配（一次对象，一次控制块）
// 2. 可能异常不安全
```

### 3.6 shared_ptr的线程安全性

```cpp
// shared_ptr的引用计数操作是原子操作
std::shared_ptr<int> global_ptr = std::make_shared<int>(42);

// 线程安全的引用计数操作
void thread_func() {
    std::shared_ptr<int> local_ptr = global_ptr;  // 原子操作
    // 使用local_ptr...
}

// 但是：shared_ptr对象本身不是线程安全的
// 多个线程同时修改同一个shared_ptr对象需要同步
std::shared_ptr<int> shared = std::make_shared<int>(42);
std::mutex mtx;

void update_shared() {
    std::lock_guard<std::mutex> lock(mtx);
    shared = std::make_shared<int>(100);  // 需要加锁
}
```

### 3.7 shared_ptr的性能考虑

```cpp
// shared_ptr的开销：
// 1. 控制块内存（引用计数、弱引用计数、删除器）
// 2. 原子操作的开销（引用计数修改）
// 3. 两次内存分配（如果不使用make_shared）

// 性能优化：使用make_shared
auto ptr = std::make_shared<int>(42);  // 一次分配

// 性能优化：如果只有一个所有者，使用unique_ptr
std::unique_ptr<int> ptr = std::make_unique<int>(42);

// 性能优化：避免循环引用
class Node {
public:
    std::shared_ptr<Node> next;
    std::weak_ptr<Node> prev;  // 使用weak_ptr避免循环引用
};
```

## 四、weak_ptr

### 4.1 基本用法

```cpp
#include <memory>

// 创建weak_ptr
std::shared_ptr<int> shared = std::make_shared<int>(42);
std::weak_ptr<int> weak = shared;  // 不增加引用计数

// 检查过期
if (weak.expired()) {
    std::cout << "Object has been destroyed" << std::endl;
}

// 获取shared_ptr
std::shared_ptr<int> locked = weak.lock();
if (locked) {
    std::cout << *locked << std::endl;
}

// 引用计数
std::cout << weak.use_count();  // 1（shared_ptr的引用计数）
```

### 4.2 避免循环引用

```cpp
// 问题：循环引用导致内存泄漏
class Node {
public:
    std::shared_ptr<Node> next;
    std::shared_ptr<Node> prev;  // 问题！
    
    ~Node() { std::cout << "Node destroyed" << std::endl; }
};

void circular_reference() {
    auto node1 = std::make_shared<Node>();
    auto node2 = std::make_shared<Node>();
    
    node1->next = node2;
    node2->prev = node1;  // 循环引用，永远不会被删除
}

// 解决：使用weak_ptr
class Node {
public:
    std::shared_ptr<Node> next;
    std::weak_ptr<Node> prev;  // 使用weak_ptr
    
    ~Node() { std::cout << "Node destroyed" << std::endl; }
};

void no_circular_reference() {
    auto node1 = std::make_shared<Node>();
    auto node2 = std::make_shared<Node>();
    
    node1->next = node2;
    node2->prev = node1;  // weak_ptr不增加引用计数
    
}  // 正确释放
```

### 4.3 观察者模式

```cpp
class Subject {
public:
    void register_observer(std::weak_ptr<Observer> observer) {
        observers_.push_back(observer);
    }
    
    void notify() {
        for (auto& weak_obs : observers_) {
            auto obs = weak_obs.lock();
            if (obs) {
                obs->update();
            }
        }
    }
    
private:
    std::vector<std::weak_ptr<Observer>> observers_;
};

class Observer {
public:
    void update() {
        std::cout << "Observer updated" << std::endl;
    }
};

// 使用
auto subject = std::make_shared<Subject>();
auto obs1 = std::make_shared<Observer>();
auto obs2 = std::make_shared<Observer>();

subject->register_observer(obs1);
subject->register_observer(obs2);

// obs1可以被销毁，不影响subject
obs1.reset();
subject->notify();  // 只通知obs2
```

### 4.4 缓存模式

```cpp
template<typename Key, typename Value>
class Cache {
public:
    void put(const Key& key, std::shared_ptr<Value> value) {
        cache_[key] = value;
    }
    
    std::shared_ptr<Value> get(const Key& key) {
        auto it = cache_.find(key);
        if (it != cache_.end()) {
            return it->second.lock();  // 返回shared_ptr
        }
        return nullptr;
    }
    
    void cleanup() {
        for (auto it = cache_.begin(); it != cache_.end(); ) {
            if (it->second.expired()) {
                it = cache_.erase(it);
            } else {
                ++it;
            }
        }
    }
    
private:
    std::unordered_map<Key, std::weak_ptr<Value>> cache_;
};
```

## 五、智能指针的最佳实践

### 5.1 使用make_unique和make_shared

```cpp
// 好的实践
auto ptr1 = std::make_unique<int>(42);
auto ptr2 = std::make_shared<std::string>("Hello");

// 避免的做法
std::unique_ptr<int> ptr3(new int(42));
std::shared_ptr<std::string> ptr4(new std::string("Hello"));
```

### 5.2 正确传递智能指针

```cpp
// 按值传递（拷贝shared_ptr）
void func1(std::shared_ptr<MyClass> ptr) {
    // 引用计数增加
}

// 按const引用传递（不增加引用计数）
void func2(const std::shared_ptr<MyClass>& ptr) {
    // 不增加引用计数，性能更好
}

// 按右值引用传递（移动unique_ptr）
void func3(std::unique_ptr<MyClass> ptr) {
    // 接管所有权
}

// 使用
auto shared = std::make_shared<MyClass>();
func1(shared);      // 引用计数 = 2
func2(shared);      // 引用计数 = 1

auto unique = std::make_unique<MyClass>();
func3(std::move(unique));  // 转移所有权
```

### 5.3 在类中使用智能指针

```cpp
class MyClass {
public:
    MyClass() : data_(std::make_unique<int[]>(100)) {}
    
    // 禁止拷贝（如果使用unique_ptr）
    MyClass(const MyClass&) = delete;
    MyClass& operator=(const MyClass&) = delete;
    
    // 允许移动
    MyClass(MyClass&&) noexcept = default;
    MyClass& operator=(MyClass&&) noexcept = default;
    
private:
    std::unique_ptr<int[]> data_;          // 独占所有权
    std::shared_ptr<ResourceManager> manager_;  // 共享所有权
    std::weak_ptr<Observer> observer_;    // 观察者
};
```

### 5.4 避免原始指针混用

```cpp
// 好的实践：统一使用智能指针
class MyClass {
public:
    void set_data(std::shared_ptr<Data> data) {
        data_ = data;
    }
    
    std::shared_ptr<Data> get_data() const {
        return data_;
    }
    
private:
    std::shared_ptr<Data> data_;
};

// 避免混合使用原始指针和智能指针
// 会导致生命周期管理混乱
```

### 5.5 处理循环引用

```cpp
// 总是使用weak_ptr打破循环引用
class Parent {
public:
    void add_child(std::shared_ptr<Child> child) {
        children_.push_back(child);
        child->parent_ = this->shared_from_this();  // weak_ptr
    }
    
private:
    std::vector<std::shared_ptr<Child>> children_;
};

class Child : public std::enable_shared_from_this<Child> {
public:
    void set_parent(std::shared_ptr<Parent> parent) {
        parent_ = parent;
    }
    
private:
    std::weak_ptr<Parent> parent_;  // 使用weak_ptr避免循环引用
};
```

## 六、enable_shared_from_this

### 6.1 基本用法

```cpp
class MyClass : public std::enable_shared_from_this<MyClass> {
public:
    std::shared_ptr<MyClass> get_shared() {
        return shared_from_this();  // 获取this的shared_ptr
    }
};

// 使用
auto obj = std::make_shared<MyClass>();
auto shared = obj->get_shared();  // 正确
```

### 6.2 enable_shared_from_this的原理

```cpp
// enable_shared_from_this的内部实现
template<typename T>
class enable_shared_from_this {
private:
    mutable std::weak_ptr<T> weak_this_;
    
public:
    std::shared_ptr<T> shared_from_this() {
        return weak_this_.lock();
    }
    
    std::shared_ptr<const T> shared_from_this() const {
        return weak_this_.lock();
    }
    
protected:
    enable_shared_from_this() = default;
    enable_shared_from_this(const enable_shared_from_this&) = default;
    enable_shared_from_this& operator=(const enable_shared_from_this&) = default;
    ~enable_shared_from_this() = default;
};

// make_shared会设置weak_this_
```

### 6.3 enable_shared_from_this的应用

```cpp
class AsyncTask : public std::enable_shared_from_this<AsyncTask> {
public:
    void start() {
        // 将this传递给异步操作
        std::thread([self = shared_from_this()]() {
            self->run();
        }).detach();
    }
    
    void run() {
        // 异步执行
        std::cout << "Task running" << std::endl;
    }
};

// 使用
auto task = std::make_shared<AsyncTask>();
task->start();
```

## 八、面试常见问题

### Q1: 智能指针有哪些类型？有什么区别？

**答案：**
C++11提供了三种智能指针：
1. **unique_ptr**：独占所有权，不可拷贝，只能移动
2. **shared_ptr**：共享所有权，使用引用计数，可拷贝
3. **weak_ptr**：观察者指针，不影响引用计数，避免循环引用

### Q2: 为什么优先使用make_unique和make_shared？

**答案：**
1. **异常安全**：避免内存泄漏
2. **性能更好**：一次内存分配（对象和控制块在一起）
3. **代码简洁**：不需要重复类型
4. **更好的缓存局部性**

### Q3: shared_ptr的引用计数是线程安全的吗？

**答案：**
是的，shared_ptr的引用计数操作是原子操作，但是：
- 引用计数的修改是线程安全的
- shared_ptr对象本身的读写不是线程安全的
- 多个线程同时修改同一个shared_ptr对象需要同步

### Q4: 什么是循环引用？如何避免？

**答案：**
循环引用是指两个或多个对象通过shared_ptr相互引用，导致引用计数永远不为0，内存无法释放。

**避免方法：**
- 使用weak_ptr打破循环引用
- 仔细设计对象之间的所有权关系

### Q5: weak_ptr有什么用途？

**答案：**
1. **避免循环引用**：打破shared_ptr的循环引用
2. **观察者模式**：观察对象而不影响其生命周期
3. **缓存**：缓存对象引用，允许对象被销毁
4. **临时访问**：临时访问对象，不增加引用计数

### Q6: enable_shared_from_this的作用是什么？

**答案：**
enable_shared_from_this允许类成员函数返回this的shared_ptr，这在需要将this作为shared_ptr传递时很有用。

**注意：**
- 对象必须由shared_ptr管理
- 不能在构造函数中使用shared_from_this

### Q7: 智能指针与原始指针如何互转？

**答案：**
```cpp
// 智能指针转原始指针
std::shared_ptr<int> ptr = std::make_shared<int>(42);
int* raw = ptr.get();  // 获取原始指针

// 原始指针转智能指针
int* raw = new int(42);
std::shared_ptr<int> ptr(raw);  // 不推荐，容易出错

// 推荐使用别名构造函数
std::shared_ptr<int> ptr(std::shared_ptr<int>(), raw);  // 别名构造函数
```

### Q8: 如何在多线程中使用shared_ptr？

**答案：**
```cpp
// 多个线程读取shared_ptr是安全的
std::shared_ptr<int> global_ptr = std::make_shared<int>(42);

void read_func() {
    std::shared_ptr<int> local = global_ptr;  // 原子操作
    // 使用local...
}

// 多个线程写入shared_ptr需要同步
std::shared_ptr<int> global_ptr;
std::mutex mtx;

void write_func() {
    std::lock_guard<std::mutex> lock(mtx);
    global_ptr = std::make_shared<int>(100);  // 需要加锁
}
```

### Q9: 智能指针有什么性能开销？

**答案：**
1. **unique_ptr**：几乎零开销，与原始指针相同
2. **shared_ptr**：
   - 控制块内存
   - 原子操作的开销
   - 两次内存分配（如果不使用make_shared）
3. **weak_ptr**：与shared_ptr类似

### Q10: 如何实现自定义删除器？

**答案：**
```cpp
// 使用lambda
auto deleter = [](int* ptr) {
    std::cout << "Custom deleter" << std::endl;
    delete ptr;
};

std::unique_ptr<int, decltype(deleter)> ptr(new int(42), deleter);

// 使用函数对象
struct FileDeleter {
    void operator()(FILE* file) const {
        if (file) fclose(file);
    }
};

std::unique_ptr<FILE, FileDeleter> file_ptr(fopen("test.txt", "w"));
```

## 九、最佳实践总结

### 9.1 智能指针使用指南

1. **优先使用智能指针**：避免原始指针
2. **选择合适的类型**：unique_ptr、shared_ptr、weak_ptr
3. **使用make函数**：make_unique、make_shared
4. **避免循环引用**：使用weak_ptr
5. **正确传递参数**：按值或const引用
6. **在类中使用**：正确处理所有权
7. **异常安全**：确保资源正确释放

### 9.2 常见陷阱

1. **循环引用**：使用weak_ptr避免
2. **this指针**：使用enable_shared_from_this
3. **混合使用**：不要混用原始指针和智能指针
4. **线程安全**：注意shared_ptr的线程安全性
5. **性能考虑**：选择合适的智能指针类型

## 十、总结

智能指针是现代C++内存管理的核心工具：

**核心概念：**
1. unique_ptr：独占所有权
2. shared_ptr：共享所有权，引用计数
3. weak_ptr：观察者，避免循环引用
4. RAII：资源获取即初始化

**优势：**
1. 自动内存管理
2. 异常安全
3. 避免内存泄漏
4. 明确所有权语义

**最佳实践：**
1. 优先使用make_unique和make_shared
2. 选择合适的智能指针类型
3. 避免循环引用
4. 正确处理多线程
5. 在类中正确使用智能指针

掌握智能指针是现代C++开发的基本功，也是面试中的必考点。
