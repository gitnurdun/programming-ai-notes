# C++面试100问

## 一、基础知识 (1-20)

### 1. 什么是C++？C和C++有什么区别？

**答案：**
C++是一种通用编程语言，支持多种编程范式（面向对象、泛型、过程化）。

**C和C++的区别：**
- **面向对象**：C++支持类、继承、多态，C不支持
- **泛型编程**：C++有模板，C没有
- **标准库**：C++有STL（容器、算法、迭代器），C只有基础库
- **异常处理**：C++支持try-catch，C不支持
- **命名空间**：C++有namespace，C没有
- **引用**：C++支持引用，C只有指针
- **运算符重载**：C++支持，C不支持

### 2. 解释C++中的左值和右值

**答案：**
- **左值（lvalue）**：有名字、可以取地址的表达式，代表持久对象
  ```cpp
  int x = 10;  // x是左值
  ```
- **右值（rvalue）**：临时对象、字面值，即将销毁的对象
  ```cpp
  10;         // 右值
  x + 1;      // 右值
  func();     // 右值（返回非引用类型）
  ```

### 3. 什么是悬空指针？如何避免？

**答案：**
悬空指针是指指向已经释放内存的指针。

**避免方法：**
1. 使用智能指针（unique_ptr, shared_ptr）
2. 释放后立即置空
3. 使用RAII原则
4. 避免返回局部变量的地址

```cpp
// 好的做法
std::unique_ptr<int> ptr = std::make_unique<int>(42);

// 避免
int* ptr = new int(42);
delete ptr;
// ptr现在是悬空指针
ptr = nullptr;  // 立即置空
```

### 4. 什么是野指针？

**答案：**
野指针是指未初始化或已被释放但未置空的指针。

**避免方法：**
1. 始终初始化指针
2. 释放后置空
3. 使用智能指针

```cpp
// 避免
int* ptr;  // 未初始化，野指针

// 好的做法
int* ptr = nullptr;
ptr = new int(42);
delete ptr;
ptr = nullptr;
```

### 5. 什么是内存泄漏？如何检测和避免？

**答案：**
内存泄漏是指程序动态分配的内存没有释放，导致可用内存减少。

**检测方法：**
1. 使用Valgrind（Linux）
2. 使用Visual Studio的诊断工具
3. 使用智能指针
4. 代码审查

**避免方法：**
1. 使用RAII（智能指针）
2. 使用容器自动管理内存
3. 遵循所有权规则

```cpp
// 好的做法：使用智能指针
std::unique_ptr<int> ptr = std::make_unique<int>(42);
// 自动释放

// 避免：手动管理
int* ptr = new int(42);
// 忘记delete，内存泄漏
```

### 6. 解释new和malloc的区别

**答案：**

| 特性 | new | malloc |
|------|-----|--------|
| 语言特性 | C++运算符 | C函数 |
| 类型安全 | 是 | 否 |
| 构造函数 | 调用 | 不调用 |
| 失败处理 | 抛出bad_alloc | 返回nullptr |
| 大小计算 | 自动 | 需要手动指定 |
| 重载 | 可以重载 | 不能重载 |
| 释放 | delete | free |

### 7. 什么是栈溢出？如何避免？

**答案：**
栈溢出是指程序使用的栈空间超过了系统分配的大小。

**原因：**
1. 过深的递归
2. 过大的局部变量
3. 无限递归

**避免方法：**
1. 限制递归深度
2. 使用迭代代替递归
3. 使用堆分配大对象
4. 增加栈大小

```cpp
// 避免：过深的递归
int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);  // 可能栈溢出
}

// 好的做法：迭代
int factorial(int n) {
    int result = 1;
    for (int i = 2; i <= n; ++i) {
        result *= i;
    }
    return result;
}
```

### 8. 什么是堆碎片？如何减少？

**答案：**
堆碎片是由于频繁的内存分配和释放导致内存不连续。

**减少方法：**
1. 使用内存池
2. 预分配大块内存
3. 使用固定大小的分配器
4. 减少频繁的小对象分配

```cpp
// 内存池示例
class MemoryPool {
    void* allocate(size_t size);
    void deallocate(void* ptr);
};
```

### 9. 解释深拷贝和浅拷贝

**答案：**
- **浅拷贝**：只拷贝指针值，不拷贝指向的内容
- **深拷贝**：拷贝指针指向的内容

```cpp
class MyClass {
    int* data;
    
    // 浅拷贝（错误）
    MyClass(const MyClass& other) : data(other.data) {}
    
    // 深拷贝（正确）
    MyClass(const MyClass& other) {
        data = new int(*other.data);
    }
};
```

### 10. 什么是RAII？

**答案：**
RAII（Resource Acquisition Is Initialization）资源获取即初始化，是一种C++编程惯用法。

**原理：**
资源的生命周期与对象的生命周期绑定，在构造函数中获取资源，在析构函数中释放资源。

**优势：**
1. 异常安全
2. 防止资源泄漏
3. 代码简洁

```cpp
class FileHandler {
public:
    FileHandler(const char* filename) 
        : file_(fopen(filename, "r")) {
        if (!file_) throw std::runtime_error("Cannot open file");
    }
    
    ~FileHandler() {
        if (file_) fclose(file_);  // 自动释放
    }
    
private:
    FILE* file_;
};

// 使用
{
    FileHandler fh("test.txt");  // 自动管理文件
}  // 自动关闭文件
```

### 11. 什么是Pimpl惯用法？

**答案：**
Pimpl（Pointer to Implementation）是一种隐藏实现细节的技术。

**优势：**
1. 减少编译依赖
2. 加速编译
3. 保持ABI稳定

```cpp
// 头文件
class MyClass {
public:
    MyClass();
    ~MyClass();
    void do_something();
    
private:
    class Impl;
    Impl* impl_;
};

// 实现文件
class MyClass::Impl {
public:
    void do_something() {
        std::cout << "Implementation" << std::endl;
    }
};

MyClass::MyClass() : impl_(new Impl()) {}
MyClass::~MyClass() { delete impl_; }
void MyClass::do_something() { impl_->do_something(); }
```

### 12. 什么是虚函数？如何实现多态？

**答案：**
虚函数是C++实现运行时多态的机制。

**原理：**
通过虚函数表（vtable）实现，每个包含虚函数的类都有一个vtable，存储虚函数的地址。

```cpp
class Base {
public:
    virtual void func() {
        std::cout << "Base::func" << std::endl;
    }
    
    virtual ~Base() = default;
};

class Derived : public Base {
public:
    void func() override {
        std::cout << "Derived::func" << std::endl;
    }
};

// 使用
Base* ptr = new Derived();
ptr->func();  // 调用Derived::func
delete ptr;
```

### 13. 什么是纯虚函数？什么是抽象类？

**答案：**
- **纯虚函数**：没有实现的虚函数，语法`= 0`
- **抽象类**：包含至少一个纯虚函数的类，不能实例化

```cpp
class Shape {
public:
    virtual double area() const = 0;  // 纯虚函数
    virtual ~Shape() = default;
};

class Circle : public Shape {
public:
    double area() const override {
        return 3.14159 * radius_ * radius_;
    }
    
private:
    double radius_;
};

// Shape是抽象类，不能实例化
// Shape s;  // 错误
Circle c;  // 正确
```

### 14. 什么是虚析构函数？为什么需要？

**答案：**
虚析构函数是声明为virtual的析构函数。

**为什么需要：**
当通过基类指针删除派生类对象时，虚析构函数确保调用正确的析构函数。

```cpp
class Base {
public:
    virtual ~Base() {  // 虚析构函数
        std::cout << "Base destructor" << std::endl;
    }
};

class Derived : public Base {
public:
    ~Derived() override {
        std::cout << "Derived destructor" << std::endl;
    }
};

// 使用
Base* ptr = new Derived();
delete ptr;  // 调用Derived析构函数，然后Base析构函数
```

### 15. 什么是虚函数表（vtable）？

**答案：**
虚函数表是编译器为每个包含虚函数的类创建的静态数组，存储虚函数的地址。

**工作原理：**
1. 每个对象包含指向vtable的指针（vptr）
2. vtable存储该类所有虚函数的地址
3. 调用虚函数时，通过vptr查找vtable，然后调用函数

### 16. 什么是多重继承？有什么问题？

**答案：**
多重继承是指一个类可以从多个基类继承。

**问题：**
1. **菱形继承**：基类被多次继承
2. **二义性**：同名成员冲突
3. **复杂度增加**

**解决方案：虚继承**

```cpp
// 菱形继承
class A {
public:
    int value;
};

class B : virtual public A {};  // 虚继承
class C : virtual public A {};  // 虚继承
class D : public B, public C {
    // 只有一个A的副本
};
```

### 17. 什么是虚继承？

**答案：**
虚继承解决菱形继承问题，确保基类只有一个副本。

```cpp
class A {
public:
    int value;
};

class B : virtual public A {};
class C : virtual public A {};
class D : public B, public C {};

// D只有一个A的副本
D d;
d.value = 10;  // 无二义性
```

### 18. 什么是友元函数？什么是友元类？

**答案：**
- **友元函数**：可以访问类的私有和保护成员的非成员函数
- **友元类**：可以访问类的私有和保护成员的类

```cpp
class MyClass {
private:
    int private_value;
    
    // 友元函数
    friend void friend_function(MyClass& obj);
    
    // 友元类
    friend class FriendClass;
};

void friend_function(MyClass& obj) {
    obj.private_value = 10;  // 可以访问私有成员
}

class FriendClass {
public:
    void access(MyClass& obj) {
        obj.private_value = 20;  // 可以访问私有成员
    }
};
```

### 19. 什么是运算符重载？如何重载？

**答案：**
运算符重载是为自定义类型定义运算符的行为。

**方式：**
1. 成员函数
2. 非成员函数

```cpp
class Complex {
public:
    double real, imag;
    
    Complex(double r, double i) : real(r), imag(i) {}
    
    // 成员函数重载
    Complex operator+(const Complex& other) const {
        return Complex(real + other.real, imag + other.imag);
    }
    
    // 友元函数重载（用于左操作数不是类类型）
    friend Complex operator*(double scalar, const Complex& c);
};

Complex operator*(double scalar, const Complex& c) {
    return Complex(scalar * c.real, scalar * c.imag);
}

// 使用
Complex c1(1, 2), c2(3, 4);
Complex c3 = c1 + c2;  // (4, 6)
Complex c4 = 2 * c1;    // (2, 4)
```

### 20. 什么是const成员函数？

**答案：**
const成员函数承诺不修改对象状态，可以用于const对象。

```cpp
class MyClass {
public:
    int get_value() const {  // const成员函数
        return value_;  // 可以读取
        // value_ = 10;  // 错误：不能修改
    }
    
    void set_value(int value) {
        value_ = value;
    }
    
private:
    int value_;
};

// 使用
const MyClass obj;
obj.get_value();  // OK
// obj.set_value(10);  // 错误：不能调用非const成员函数
```

## 二、C++11新特性 (21-40)

### 21. 什么是右值引用？

**答案：**
右值引用是C++11引入的引用类型，只能绑定到右值（临时对象）。

```cpp
int&& rref1 = 10;  // 绑定到字面量
int&& rref2 = std::move(x);  // 将左值转换为右值引用

std::string&& rref3 = std::string("hello");  // 绑定到临时对象
```

### 22. 什么是移动语义？

**答案：**
移动语义允许将资源从一个对象"移动"到另一个对象，而不是拷贝。

**优势：**
避免不必要的深拷贝，提高性能。

```cpp
class MyClass {
public:
    // 移动构造函数
    MyClass(MyClass&& other) noexcept
        : data_(other.data_) {
        other.data_ = nullptr;
    }
    
private:
    int* data_;
};

// 使用
MyClass obj1;
MyClass obj2 = std::move(obj1);  // 移动，不拷贝
```

### 23. 什么是std::move？

**答案：**
std::move将左值转换为右值引用，启用移动语义。

```cpp
std::string str1 = "Hello";
std::string str2 = str1;        // 拷贝
std::string str3 = std::move(str1);  // 移动
// str1现在为空
```

### 24. 什么是完美转发？

**答案：**
完美转发是指在函数模板中，将参数精确地转发给另一个函数，保持参数的值类别。

```cpp
template<typename T>
void wrapper(T&& arg) {
    target(std::forward<T>(arg));  // 完美转发
}

void target(std::string& arg) {
    std::cout << "Lvalue reference" << std::endl;
}

void target(std::string&& arg) {
    std::cout << "Rvalue reference" << std::endl;
}
```

### 25. 什么是万能引用？

**答案：**
万能引用是可以绑定到左值或右值的引用，形式为`T&&`。

```cpp
template<typename T>
void func(T&& arg);  // T&& 是万能引用

// 使用
int x = 10;
func(x);     // 绑定到左值，T推导为int&
func(10);    // 绑定到右值，T推导为int
```

### 26. 什么是智能指针？

**答案：**
智能指针是管理动态内存的类模板，自动释放内存。

**类型：**
1. unique_ptr：独占所有权
2. shared_ptr：共享所有权
3. weak_ptr：观察者指针

```cpp
auto ptr1 = std::make_unique<int>(42);
auto ptr2 = std::make_shared<int>(42);
std::weak_ptr<int> ptr3 = ptr2;
```

### 27. unique_ptr和shared_ptr有什么区别？

**答案：**

| 特性 | unique_ptr | shared_ptr |
|------|-----------|------------|
| 所有权 | 独占 | 共享 |
| 拷贝 | 不可拷贝 | 可拷贝 |
| 移动 | 可移动 | 可移动 |
| 引用计数 | 无 | 有 |
| 性能 | 更好 | 稍差 |

### 28. 什么是weak_ptr？有什么用途？

**答案：**
weak_ptr是观察者指针，不影响引用计数。

**用途：**
1. 避免循环引用
2. 观察对象而不影响其生命周期
3. 缓存

```cpp
std::shared_ptr<int> shared = std::make_shared<int>(42);
std::weak_ptr<int> weak = shared;  // 不增加引用计数

if (auto locked = weak.lock()) {  // 获取shared_ptr
    std::cout << *locked << std::endl;
}
```

### 29. 什么是Lambda表达式？

**答案：**
Lambda表达式是匿名函数，可以在代码中直接定义和使用。

```cpp
auto lambda = [](int x, int y) {
    return x + y;
};

int result = lambda(10, 20);  // 30
```

### 30. Lambda表达式的捕获列表有哪些？

**答案：**
- `[x]`：按值捕获x
- `[&x]`：按引用捕获x
- `[=]`：按值捕获所有
- `[&]`：按引用捕获所有
- `[=, &x]`：x按引用，其他按值
- `[&, x]`：x按值，其他按引用

### 31. 什么是auto类型推导？

**答案：**
auto是C++11引入的类型推导关键字，编译器自动推导变量类型。

```cpp
auto x = 42;                    // int
auto y = 3.14;                  // double
```

### 32. 什么是decltype？

**答案：**
decltype推导表达式的确切类型，保留引用和const。

```cpp
int x = 42;
decltype(x) y = 100;  // int

const int& cref = x;
decltype(cref) z = x;  // const int&
```

### 33. auto和decltype有什么区别？

**答案：**
- **auto**：推导类型时丢弃引用和const
- **decltype**：推导表达式的确切类型，保留引用和const

```cpp
int x = 42;
const int& cref = x;

auto a = cref;      // int（丢弃const和引用）
decltype(cref) b = x;  // const int&（保留）
```

### 34. 什么是constexpr？

**答案：**
constexpr是C++11引入的关键字，表示可以在编译时求值的常量表达式。

```cpp
constexpr int square(int x) {

constexpr int result = square(5);  // 编译时计算
```

### 35. 什么是nullptr？

**答案：**
nullptr是C++11引入的空指针常量，类型是std::nullptr_t。

**优势：**
1. 类型安全
2. 避免重载歧义

```cpp
int* ptr = nullptr;
void func(int x);

```

### 36. 什么是enum class？

**答案：**
enum class是C++11引入的强类型枚举。

**优势：**
1. 作用域限定
2. 不隐式转换为int
3. 可指定底层类型

```cpp
enum class Color {
```

### 37. 什么是范围for循环？

**答案：**
范围for循环是C++11引入的简化遍历容器的语法。

```cpp
std::vector<int> vec = {1, 2, 3, 4, 5};

// 传统方式
for (std::vector<int>::iterator it = vec.begin(); it != vec.end(); ++it) {
    std::cout << *it << std::endl;
}

// 范围for
for (int elem : vec) {
    std::cout << elem << std::endl;
}

// 使用引用修改
for (int& elem : vec) {
    elem *= 2;
}
```

### 38. 什么是override和final？

**答案：**
- **override**：确保函数覆盖基类虚函数
- **final**：禁止函数被进一步覆盖或类被继承

```cpp
class Base {
public:
    virtual void func() {}
};

class Derived : public Base {
public:
    void func() override {}  // 确保覆盖
};

class FinalClass final {};  // 不能被继承
```

### 39. 什么是noexcept？

**答案：**
noexcept指示函数不会抛出异常。

**用途：**
1. 帮助编译器优化
2. 允许STL使用移动操作

```cpp
void func() noexcept {
    // 不会抛出异常
}

class MyClass {
public:
    MyClass(MyClass&&) noexcept {}  // 移动操作应该是noexcept
};
```

### 40. 什么是default和delete？

**答案：**
- **= default**：显式请求编译器生成默认版本
- **= delete**：显式禁止某个函数

```cpp
class MyClass {
public:
    MyClass() = default;  // 使用默认构造函数
    MyClass(const MyClass&) = delete;  // 禁止拷贝
};
```

## 三、模板与泛型编程 (41-60)

### 41. 什么是函数模板？

**答案：**
函数模板是定义通用函数的机制，可以处理多种类型。


### 42. 什么是类模板？

**答案：**
类模板是定义通用类的机制，可以处理多种类型。

```cpp
template<typename T>
class Stack {
public:
    void push(const T& value);
    T pop();
    
private:
    std::vector<T> data_;
};

// 使用
Stack<int> int_stack;
Stack<std::string> string_stack;
```

### 43. 什么是模板特化？

**答案：**
模板特化是为特定类型提供特殊实现的机制。

**全特化：**
```cpp
template<typename T>
class MyClass {
    // 通用版本
};

// 全特化
template<>

    // int的特殊版本
};
```

**偏特化：**
```cpp
template<typename T, typename U>
class MyClass {
    // 通用版本
};

// 偏特化
template<typename T>
class MyClass<T, int> {
    // 第二个参数是int的特殊版本
};
```

### 44. 什么是SFINAE？

**答案：**
SFINAE（Substitution Failure Is Not An Error）是模板参数推导失败不是错误的机制。

**用途：**
1. 类型检测
2. 重载决议
3. 约束模板

```cpp
template<typename T>
typename std::enable_if<std::is_integral<T>::value, T>::type
add(T a, T b) {
    return a + b;
}
```

### 45. 什么是类型萃取（Type Traits）？

**答案：**

```cpp
static_assert(std::is_integral_v<int>);
static_assert(std::is_floating_point_v<double>);

// 类型转换

```

### 46. 什么是变参模板？

**答案：**
变参模板是接受可变数量模板参数的模板。


### 47. 什么是折叠表达式？

**答案：**

### 48. 什么是CRTP？

**答案：**
CRTP（Curiously Recurring Template Pattern）是奇异递归模板模式，派生类将自己作为模板参数传递给基类。

**用途：**
1. 静态多态
2. 代码复用

```cpp
template<typename Derived>
class Base {
public:
    void interface() {
        static_cast<Derived*>(this)->implementation();
    }
};

class Derived : public Base<Derived> {
public:
    void implementation() {
        std::cout << "Derived implementation" << std::endl;
    }
};
```

## 四、标准库 (61-80)

### 51. 什么是STL？

**答案：**

3. **迭代器**：容器和算法之间的桥梁
4. **函数对象**：less, greater等
5. **分配器**：管理内存

### 52. vector和list有什么区别？

**答案：**

| 特性 | vector | list |
|------|--------|------|
| 内存结构 | 连续内存 | 双向链表 |
| 随机访问 | O(1) | O(n) |
| 插入删除 | O(n) | O(1) |
| 缓存友好 | 是 | 否 |
| 大小 | 动态 | 动态 |

### 53. map和unordered_map有什么区别？

**答案：**

| 特性 | map | unordered_map |
|------|-----|---------------|
| 实现 | 红黑树 | 哈希表 |
| 查找复杂度 | O(log n) | O(1)平均 |
| 有序 | 是（按键排序） | 否 |
| 迭代器失效 | 很少 | 重组时失效 |

### 54. 什么是迭代器？

### 55. 什么是算法库？

## 五、并发编程 (81-100)

### 61. 什么是std::thread？

**答案：**
std::thread是C++11引入的线程类，用于创建和管理线程。

```cpp
void worker() {
```

### 62. 什么是互斥量？

**答案：**
互斥量是用于保护共享数据的同步原语。

```cpp
std::mutex mtx;
int shared_data = 0;

void increment() {
    std::lock_guard<std::mutex> lock(mtx);
    ++shared_data;
}
```

### 63. lock_guard和unique_lock有什么区别？

**答案：**
- **lock_guard**：简单，只能在构造时加锁
- **unique_lock**：灵活，支持手动加锁/解锁

```cpp
// lock_guard
std::lock_guard<std::mutex> lock(mtx);

// unique_lock
std::unique_lock<std::mutex> lock(mtx);
lock.unlock();
lock.lock();
```

### 64. 什么是条件变量？

**答案：**
条件变量用于线程间同步，允许线程等待某个条件成立。

```cpp
std::mutex mtx;
std::condition_variable cv;
bool ready = false;

void worker() {
    std::unique_lock<std::mutex> lock(mtx);
    cv.wait(lock, [] { return ready; });
    // 执行工作
}

void signal() {
    {
        std::lock_guard<std::mutex> lock(mtx);
        ready = true;
    }
    cv.notify_one();
}
```

### 65. 什么是原子操作？

**答案：**
原子操作是不可分割的操作，不会被线程调度打断。

```cpp
std::atomic<int> counter(0);

void increment() {
    counter.fetch_add(1, std::memory_order_relaxed);
}
```

### 66. 什么是std::promise和std::future？

**答案：**
- **std::promise**：生产者，用于设置值或异常
- **std::future**：消费者，用于获取值或异常

```cpp
std::promise<int> prom;
std::future<int> fut = prom.get_future();

std::thread t([&prom]() {
    prom.set_value(42);
});

int result = fut.get();  // 等待并获取值
t.join();
```

### 67. 什么是std::async？

**答案：**
std::async用于异步执行任务，返回future。

```cpp
int async_work() {
    std::this_thread::sleep_for(std::chrono::seconds(2));
    return 42;
}

std::future<int> fut = std::async(std::launch::async, async_work);
int result = fut.get();  // 等待并获取结果
```

### 68. 什么是std::shared_mutex（C++17）？

**答案：**
std::shared_mutex支持多个读线程或一个写线程。

```cpp
std::shared_mutex mtx;

void read() {
    std::shared_lock<std::shared_mutex> lock(mtx);
    // 读取数据
}

void write() {
    std::unique_lock<std::shared_mutex> lock(mtx);
    // 写入数据
}
```

### 69. 什么是std::jthread（C++20）？

### 70. 什么是竞态条件？

**答案：**
竞态条件是指多个线程同时访问和修改共享数据，导致结果依赖于线程执行顺序。

**避免方法：**
1. 使用互斥量
2. 使用原子操作
3. 使用线程安全的数据结构

### 71. 什么是死锁？

**答案：**
死锁是指两个或多个线程互相等待对方释放资源，导致所有线程都无法继续执行。

**避免方法：**
1. 固定加锁顺序
2. 使用std::lock
3. 使用try_lock
4. 设置超时

### 72. 什么是数据竞争？

**答案：**
数据竞争是指两个或多个线程同时访问同一内存位置，至少一个是写操作，且没有同步。

**避免方法：**
1. 使用互斥量
2. 使用原子操作
3. 使用线程安全的数据结构

### 73. 什么是内存序？

**答案：**
内存序指定原子操作的内存可见性规则。

**类型：**
1. memory_order_relaxed
2. memory_order_consume
3. memory_order_acquire
4. memory_order_release
5. memory_order_acq_rel
6. memory_order_seq_cst

```cpp
std::atomic<bool> ready(false);
int data = 0;

void producer() {
    data = 42;
    ready.store(true, std::memory_order_release);
}

void consumer() {
    while (!ready.load(std::memory_order_acquire)) {
        // 等待
    }
    std::cout << data << std::endl;
}
```

### 74. 什么是std::latch（C++20）？

**答案：**
std::latch是线程同步屏障，等待一定数量的线程完成。

```cpp
std::latch done(5);

void worker(int id) {
    std::cout << "Worker " << id << std::endl;
    done.count_down();
}

int main() {
    std::vector<std::jthread> workers;
    for (int i = 0; i < 5; ++i) {
        workers.emplace_back(worker, i);
    }
    
    done.wait();  // 等待所有worker完成
}
```

### 75. 什么是std::barrier（C++20）？

```cpp
        std::cout << "Worker " << id << " phase " << phase << std::endl;
        sync.arrive_and_wait();
    }
}
```

### 76. 什么是std::semaphore（C++20）？

### 79. 如何实现线程池？
