# 模块系统详解 (C++20)

## 一、模块概述

### 1.1 什么是模块

模块是C++20引入的新特性，用于替代传统的头文件系统，提供更好的编译时间和隔离性。

**优势：**
1. 更快的编译速度
2. 更好的隔离性
3. 避免宏污染
4. 更清晰的依赖关系

### 1.2 模块语法

```cpp
// 模块接口
export module mymodule;

// 导出声明
export int add(int a, int b);

export class MyClass {
public:
    void method();
};

// 模块实现
module mymodule;

int add(int a, int b) {
    return a + b;
}

void MyClass::method() {
    // 实现
}
```

## 二、模块声明

### 2.1 导出模块

```cpp
// 导出模块接口
export module math;

// 导出函数
export int add(int a, int b);
export int multiply(int a, int b);

// 导出类
export class Calculator {
public:
    int calculate(int a, int b);
};

// 导出命名空间
export namespace utils {
    void helper();
}
```

### 2.2 导入模块

```cpp
// 导入模块
import math;

// 使用
int result = add(10, 20);
Calculator calc;
```

## 三、模块分区

### 3.1 基本分区

```cpp
// 主模块
export module math;

// 导出分区
export import math.core;
export import math.utils;

// 分区接口
export module math.core;
export int add(int a, int b);

// 分区实现
module math.core;
int add(int a, int b) {
    return a + b;
}
```

## 四、全局模块片段

### 4.1 基本用法

```cpp
// 全局模块片段
module;
#include <iostream>

export module mymodule;

export void print() {
    std::cout << "Hello" << std::endl;
}
```

## 五、面试常见问题

### Q1: 模块相比头文件有什么优势？

**答案：**
1. 更快的编译速度
2. 更好的隔离性
3. 避免宏污染
4. 更清晰的依赖关系

### Q2: 如何定义模块？

**答案：**
```cpp
export module mymodule;
export void func();
```

### Q3: 如何导入模块？

**答案：**
```cpp
import mymodule;
```

### Q4: 模块分区有什么用途？

**答案：**
模块分区用于组织大型模块，提高编译效率。

## 六、最佳实践

### 6.1 使用模块替代头文件

```cpp
// 好的实践
export module mymodule;

// 避免
#ifndef MYMODULE_H
#define MYMODULE_H
// ...
#endif
```

### 6.2 合理使用分区

```cpp
export module math;
export import math.core;
export import math.utils;
```
