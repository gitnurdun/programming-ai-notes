# Programming & AI Learning Notes

A collection of Markdown tutorials, study guides, and PDF references spanning programming languages, deep learning, and interview preparation.

| Folder | Focus |
| --- | --- |
| [advanced_java_mastery](advanced_java_mastery/) | Java language features, concurrency, reflection, and design |

The root also contains learning-plan documents, `main.pdf`, and an archived copy of the LLM materials (`llm.zip`).

## Use the collection

```sh
git clone https://github.com/gitnurdun/programming-ai-notes.git
```

Browse Markdown directly on GitHub, or clone the repository and open the documents in a Markdown editor and PDF reader. There is no single application or global build step; any code excerpts have the requirements described in their own tutorials. Read the relevant section before running a snippet.

This is study material, not a bundled runtime environment or a claim that every example has been tested on every platform.
